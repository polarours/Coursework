# 选题标准 / Selection criteria

一道题值得收录，需同时满足以下条件。A problem qualifies only if it meets all of the following.

## 硬性条件 / Hard requirements

1. **来源可查 / Traceable origin**：来自知名高校的计算机课程，能给出官方课程主页或公开讲义链接。
   *Traceable origin from a reputable university CS course, with an official course page or public lecture link.*
2. **期末/大作业级别 / Capstone scale**：是课程中的大型项目，而非单周小练习；通常需要数天到数周完成。
   *A large course project, not a weekly exercise; typically days to weeks of work.*
3. **强调思考与动手 / Reasoning and implementation**：必须包含设计决策、数据结构选型或算法推导，不能只是调用 API。
   *Must involve design decisions, data-structure choices, or algorithmic reasoning — not just calling APIs.*
4. **验收清晰 / Verifiable**：有明确的测试用例或评测脚本，读者能自行判断「写对了没有」。
   *Has concrete tests so readers can verify correctness themselves.*
5. **版权可引用 / Referencable**：允许我们引用题目链接并撰写独立解析；不收录明确禁止公开讨论答案的课程。
   *We can link the statement and write an independent walkthrough; exclude courses that explicitly forbid public solutions.*

## 加分项 / Nice to have

- 知识点有迁移价值（如共识、内存管理、可靠传输）/ Transferable concepts (consensus, memory management, reliable transport).
- 难度可分阶段，适合循序渐进 / Naturally decomposes into stages of increasing difficulty.
- 有有趣的呈现形式（如 Pacman、Gitlet）/ An engaging wrapper (Pacman, Gitlet).
- 中文资料稀缺，补上真实空缺 / Scarce Chinese-language material on the topic.

## 排除项 / Exclusions

- 单纯「实现某个排序算法」式的习题 / Trivial "implement this algorithm" exercises.
- 无法运行环境或依赖不可得的题目 / Problems whose environment or dependencies cannot be obtained.
- 只有标准答案、没有思考空间的题目 / Problems with a single mechanical answer and no design space.
