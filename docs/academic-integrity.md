# 学术诚信与版权 / Academic integrity and licensing

## 我们的定位 / Our position

本项目是**学习参考**，帮助学生理解优秀题目的设计与实现；它不替代学生自己的作业，也不应用于直接提交。
This repo is a **study reference** that helps students understand design and implementation. It does not replace a student's own work and must not be submitted as homework.

## 操作准则 / Practical rules

1. 题目原文只给官方链接，不复制全文 / Link official problem statements; do not reproduce them.
2. 参考实现独立编写，不复制他人 solution 仓库 / Write reference implementations independently; don't copy existing solution repos.
3. 引用任何外部材料必须注明来源与许可 / Attribute all external material with source and license.
4. 阅读顺序引导读者先独立思考 / Guide readers to think independently before reading.
5. 不收录明确禁止公开答案讨论的课程 / Exclude courses that explicitly forbid public solution discussion.

## 读者须知 / For readers

如果你正在修读相关课程，请先确认课程对协作与公开资料的规定；把本项目当作思路参考，并按课程要求独立完成与署名。
If you are enrolled in the course, check your course's collaboration and public-material policies first. Use this repo for insight, and complete and attribute your own work as required.
