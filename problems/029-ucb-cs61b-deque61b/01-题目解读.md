## 需求概述 / Requirements

CS61B proj1a+1b 合起来是一个完整的"数据结构内建"大作业：课程给出接口 `Deque61B<T>`（9 个方法），学生要从零交出两种实现并接一个应用：

CS61B proj1a+1b together form one complete "build the data structure" project: the course hands you the `Deque61B<T>` interface (9 methods), and you deliver two implementations plus an application:

1. **proj1a 链表版 / linked version**：`LinkedListDeque61B` —— 环形双向链表 + **单哨兵节点**；`getRecursive` 必须递归。
2. **proj1b 数组版 / array version**：`ArrayDeque61B` —— 环形数组，满时翻倍、占用 < 1/4 时减半。
3. **proj1b 泛型练习 / generics drill**：`Maximizer61B.max` 两个重载（自然序 + Comparator）。
4. **proj1b 应用 / application**：`GuitarString` —— Karplus-Strong 弦振动仿真，缓冲区就是你自己实现的 Deque。

> **English:** The elegance is in the constraints: one sentinel instead of two, circular indexing instead of shifting, and a real audio simulation built on your own deque.

## 边界条件 / Edge cases

- 空结构上 remove/get 必须返回 `null` 而不是崩溃 / removes and gets on empty return null.
- 越界 `get(-1)`、`get(size)` 返回 null / out-of-range gets return null.
- 增删各操作必须 O(1)（均摊）/ all deque ops amortized O(1).
- 扩缩容时机：满 → 2x；占用 < 1/4 且容量 > 16 → /2 / grow at full, shrink below 25% usage.
