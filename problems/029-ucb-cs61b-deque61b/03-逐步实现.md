# 03 · 逐步实现 / Step-by-step implementation

## 第 1 步：LinkedListDeque61B（proj1a）

```java
// 成环：插入时四针同动 / four pointer updates per insert
Node n = new Node(x, sentinel, sentinel.next);
sentinel.next.prev = n;
sentinel.next = n;
```

`getRecursive` 走私有 helper（接口方法不便带辅助参数）：

```java
private T getRecursiveHelper(Node start, int index) {
    if (index == 0) return start.item;
    return getRecursiveHelper(start.next, index - 1);
}
```

## 第 2 步：ArrayDeque61B（proj1b）

构造：容量 8，`nextFirst = 7, nextLast = 0`（空表两指针相邻，恰好留出两端入口）。

```java
public void addFirst(T x) {
    if (size == items.length) resize(items.length * 2);  // 先扩容
    items[nextFirst] = x;          // 放在 nextFirst 处
    nextFirst = minusOne(nextFirst); // 再后退一步
    size += 1;
}
```

`removeXxx` 置 `items[i] = null` 释放引用——泛型数组的 loitering 是真实内存泄漏源。

## 第 3 步：Iterable 缺口（作业暗设计）

官方 `Maximizer61BTest`（注释里）直接把 `ArrayDeque61B` 传给 `max(Iterable<T>, ...)`，但 `Deque61B` 接口不 extends `Iterable`——**starter 文件互相不编译**。这是作业设计的一环：学生要自己发现并补 `iterator()`。参考实现用匿名内部类走环形下标。
