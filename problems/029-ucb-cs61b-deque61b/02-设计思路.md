# 02 · 设计思路 / Design

## 链表版：单哨兵成环 / Linked: one sentinel, circular

不设头尾两个哨兵，只用一个：`sentinel.next` 是首元素、`sentinel.prev` 是末元素，空表时两者都指回哨兵自己。**为什么 / Why**：两个哨兵要处理"首哨兵的 prev"和"尾哨兵的 next"这些永远走不到的指针，一个环把它们全部统一成同一条不变式——任何节点的 prev/next 永不为 null。

> **English:** With one circular sentinel, every pointer case collapses into a single invariant: no null links anywhere, so addFirst/addLast/removeFirst/removeLast share the same wiring logic.

## 数组版：下标取模 / Array: modular arithmetic

`nextFirst` 指向首元素**前一格**，`nextLast` 指向末元素**后一格**——先放后缩，"放在哪里"与"指针指向哪里"永远一致，不需要 if 分支。前进/后退统一为 `(i ± 1) mod capacity`。**为什么 / Why**：数组回绕是取模的天然应用；用两格"预留位"避免了空表/单元素等特殊情形的分支。

扩缩容走同一个 `resize`：按**逻辑顺序**搬回 `[0, size)` 后重置指针（nextFirst = length-1，nextLast = size）。

> **English:** One resize routine handles both directions: copy in logical order, then reset the two cursors — resize never needs its own wraparound cases.

## 应用：Karplus-Strong / Application: Karplus-Strong

弦 = 一个 N 样本环形缓冲（N = SR/frequency）。拨弦 = 全部换成 [-0.5, 0.5) 白噪声；每步 `tic` 出队首样本，压入 `DECAY × (首+次)/2`。低频弦缓冲长、衰减慢，天然产生音高——**而缓冲区就是刚实现的 ArrayDeque61B**，作业闭环。

> **English:** The buffer literally is your ArrayDeque61B — the project closes its own loop: the data structure you built becomes the voice of the instrument.
