# 06 · 踩坑清单 / Pitfalls

## 1. 两份 starter 互不编译 / The two starters don't compile together

- 症状 / Symptom：`no suitable method found for max(ArrayDeque61B<Integer>)`。
- 原因 / Cause：官方 `Deque61B` 不 extends `Iterable`，而 `Maximizer61B.max` 收 `Iterable`。
- 修复 / Fix：`implements Deque61B<T>, Iterable<T>` + 匿名 `iterator()`。
- 这是**故意的设计**：逼学生自己发现缺口 / This is intentional: the gap is the exercise.

> **English:** When official files refuse to compile against each other, read it as a designed puzzle, not a mistake.

## 2. 泛型数组只能造 Object[] / Generic arrays need a cast

- `items = (T[]) new Object[8]`，构造处 `@SuppressWarnings("unchecked")`。
- 直接 `new T[8]` 编译不过 / `new T[8]` is illegal in Java.

## 3. loitering 引用 / Loitering references

- 删除元素后不置 null → 对象滞留数组被 GC 拒收 / removed elements linger if the slot isn't nulled.

## 4. 缩容阈值抖动 / Shrink-threshold thrashing

- 在 1/2 处缩容会与扩容交替打架 / shrinking at 1/2 fights regrowth; use 1/4 + capacity floor.

## 5. 白噪声要逐格重抽 / Resample per slot

- pluck 对每个下标独立调 `Math.random() - 0.5`，不要先抽一个再复制 / draw fresh randomness per slot.
