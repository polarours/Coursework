## 开发中真实踩过的坑 / Real bugs hit during development

1. **接口没有 getFirst**：GuitarString 的 `tic` 第一版写了 `buffer.getFirst()` —— `Deque61B` 只有 `get(int)`。**教训 / Lesson**：动手前先把接口方法清单 grep 出来。
   *The interface has no getFirst; only get(int). Grep the full method list before writing call sites.*
2. **Maximizer 编译失败暴露作业暗设计**：`ArrayDeque61B cannot be converted to Iterable` 才注意到官方测试注释的用法——补 `implements Iterable<T>` + `iterator()`。
   *The compile error revealed the intended design: the student must add the iterator themselves.*
3. **resize 首版把搬运写复杂了**：先写了一行 `plusOne(...)%length==0 ? 0 : 0` 的废逻辑，随即简化为"从 plusOne(nextFirst) 顺序拷贝"——提醒：搬运只关心逻辑顺序，环形下标只在读取时取模。
   *Resize only needs logical order; apply modular arithmetic at read time, not inside the copy loop.*
