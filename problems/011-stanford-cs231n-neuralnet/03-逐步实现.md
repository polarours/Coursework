# 03 · 逐步实现 / Step-by-step implementation

## 阶段 1 — 前向

```python
Z1 = X @ W1 + b1
A1 = relu(Z1)
scores = A1 @ W2 + b2
probs = softmax(scores)
```

## 阶段 2 — 交叉熵损失

`L = -mean(log(probs[i][y[i]]))`

## 阶段 3 — 反向传播

dS = probs - onehot(y)，除以 n；dW2 = A1ᵀ·dS；dA1 = dS·W2ᵀ；dZ1 = dA1·1[Z1>0]；dW1 = Xᵀ·dZ1。

> **English:** The gradient chain is the heart of the exercise. We verified it with numerical gradient checking — see chapter 05.

## 阶段 4 — 训练

SGD，lr=1.0，600 轮；loss 1.0865 → 0.1248，acc 0.967。
