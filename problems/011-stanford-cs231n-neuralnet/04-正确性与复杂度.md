# 04 · 正确性与复杂度 / Correctness and complexity

## 不变量 / Invariants

1. Softmax 概率和为 1。
2. 解析梯度 = 数值梯度（梯度检验验证）。
3. 学习率合适时 loss 单调下降趋势。

> **English:** Gradient checking is the gold standard for verifying backprop: if analytic and numerical gradients match to 1e-6, the implementation is almost certainly correct.
