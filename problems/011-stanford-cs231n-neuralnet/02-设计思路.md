# 02 · 设计思路 / Design rationale

## 关键决策 / Key decisions

| 决策 / Decision | 选择 / Choice | 理由 / Why |
|---|---|---|
| 矩阵运算 | 纯 Python 列表 + 手写 matmul | 环境无 numpy；强制理解每一步 / no numpy available |
| 激活函数 | ReLU | 简单、缓解梯度消失 / simple, mitigates vanishing gradient |
| 损失 | 交叉熵 + Softmax | 分类标准组合 / standard for classification |
| 数据 | 平缓螺旋（2π，半径 2.5）| 非线性可分但纯 Python 数百轮可收敛 / nonlinear yet tractable |
| 随机性 | 固定种子 | 结果可复现 / reproducible |

> **English:** We deliberately made the spiral gentler than CS231n's original (4π, radius 4.5) because pure Python is ~100× slower than numpy. The problem is still nonlinear — a linear classifier cannot solve it.
