## 失败案例与排查 / Failures and debugging

| 症状 / Symptom | 原因 / Cause | 修复 / Fix |
|---|---|---|
| IndexError: list index out of range（backward）| dA1 = dS @ W2 的维度错了：传的是 H×C，应为 C×H（W2 转置）| 构造 W2_T = C×H 再 matmul；梯度检验通过 |
| 训练 loss 震荡不降 | 螺旋数据太难（4π、半径 4.5）+ 学习率敏感 | 改为平缓螺旋（2π、半径 2.5），lr=1.0，600 轮收敛 |

> **English:** Two distinct failures: a real dimension bug in backprop (fixed and gradient-checked), and a data-difficulty/lr issue (fixed by gentler data). Distinguishing code bugs from training dynamics is an important skill.
