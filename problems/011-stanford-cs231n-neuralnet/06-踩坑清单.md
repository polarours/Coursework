# 06 · 踩坑清单 / Pitfalls

## 1. 矩阵维度混淆 / Matrix dimension confusion

dS 是 N×C，乘 W2 前必须转置成 C×H。用梯度检验定位。

## 2. 梯度除不除 n / Averaging gradients

dS 除以 n 得到平均梯度；学习率需相应放大。混用会导致收敛过慢或发散。

## 3. 数据难度与学习率 / Data difficulty vs learning rate

loss 震荡不一定是代码 bug；先用梯度检验证明代码正确，再调数据/超参。

> **English:** Three lessons: dS (N×C) must be multiplied by W2 transposed to C×H — a real dimension bug that raised IndexError and was fixed and confirmed by gradient checking; dividing the gradient by the batch size means the learning rate must be scaled accordingly; and oscillating loss is not necessarily a code bug — gradient checking proved the code correct before we adjusted data difficulty and learning rate.
