# 01 · 题目解读 / Understanding the problem

## 需求概述 / Requirements

CS231n 的 assignment 1 让学生从零实现两层神经网络。本项目用纯 Python（无 numpy）复现完整流程：
CS231n's assignment 1 builds a two-layer network from scratch. We reproduce it in pure Python:

1. **前向传播 / Forward**：线性层 → ReLU → 线性层 → Softmax。
2. **损失 / Loss**：交叉熵。
3. **反向传播 / Backward**：手动推导梯度，SGD 更新。
4. **训练 / Training**：在螺旋形合成数据上观察 loss 下降与准确率提升。

> **English:** No autograd, no numpy — every gradient is derived and coded by hand. This is what makes it a true learning exercise.

## 验收 / Acceptance

- [x] Softmax 输出概率和为 1
- [x] 梯度检验：解析梯度与数值梯度一致（W1/W2）
- [x] 600 轮训练：loss 1.0865 → 0.1248
- [x] 准确率 0.339 → 0.967
