## 官方测试怎么读 / How to read the official tests

PublicTests 的构造区先 `addSubmission` 铺数据再断言——它就是**需求文档**：例如 `numSubmissions` 的语义、`satisfactory` 的阈值都只在断言里出现。把每个断言翻译成一句需求，是本题最有效的读法。

> **English:** Translate each assertion into one requirement sentence; the test file is the statement of work.
