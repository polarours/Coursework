# 06 · 踩坑清单 / Pitfalls

## 1. package 双层结构 / Two-package layout

- `submitserver.SubmitServer` + `tests.PublicTests`，编译要 `-d` 输出到同一 build 目录再跑，路径错会 `ClassNotFoundException`。

## 2. JUnit4 与 JUnit5 混用 / JUnit4 vs JUnit5

- 官方测试 `import org.junit.*`（JUnit4），本机只有 console-standalone（JUnit5）时编译即失败——两者 jar 不通用，需按测试代系选 jar / pick the jar matching the test's generation。

## 3. 链式 add 的返回值 / The fluent return

- `addSubmission` 忘记 `return this` 时链式调用在第一环 NPE——官方测试会暴露，自写测试也该有一条链式用例。

## 4. 序号 1-based / Submission numbers are 1-based

- `bestSubmissionNumber` 从 1 数起；off-by-one 在边界补测里当场抓出来。

## 5. "答案仓库"陷阱 / The answer-repo trap

- 搜索结果里大量 cmsc132 仓库是**学生答案集**；本题 upstream 恰是其一，但它附带了官方 PublicTests——价值在测试与对照，不在抄实现。使用方式见 02/03 章。
  *Many cmsc132 repos are answer sets; this one's value is the official tests plus a verified reference to diff against.*
