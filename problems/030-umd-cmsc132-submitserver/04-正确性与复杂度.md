# 04 · 正确性与复杂度 / Correctness & complexity

## 复杂度 / Complexity

| 操作 | 复杂度 | 说明 |
|---|---|---|
| numSubmissions() | O(n) | 遍历全部人 |
| numSubmissions(name) | O(n + k) | 找人 + 数提交 |
| bestSubmissionScore / Number | O(n + k) | 同上一趟归约 |
| addSubmission | O(n) | 查重（是否存在该生） |

对班级规模（~几十人）完全够用；渐近优化不是本作业目标。

> **English:** At classroom scale everything is effectively instant; asymptotics is deliberately not the lesson here.

## 正确性策略 / Correctness strategy

- **测试即规格**：15 个官方测试全绿 = 主语义正确
- **边界补测**：4 个自写测试锁定官方未定义行为，防止"答案碰巧过测试"
- **并列语义**：同分时 bestSubmissionNumber 的取值以实测为准并记录（官方测试恰好不覆盖并列情形——延伸练习 3 请你补上这个测试）
