# 02 · 设计思路 / Design rationale

## 关键决策 / Key decisions

| 决策 | 选择 | 理由 |
|---|---|---|
| 查找 | 哈希表 | O(1) 定位节点 |
| 顺序 | 双向链表 + 哨兵 | O(1) 移动/删除，哨兵消除边界判断 |
| 淘汰 | tail.prev | LRU 始终在尾部 |

> **English:** Each design choice trades simplicity against performance or completeness; the rationale is stated explicitly so readers can evaluate alternatives.
