# 07 · 延伸练习 / Follow-up exercises

## 练习 1 — 最优参数（中等）
给定期望元素数与假阳性率，计算最优 size 与 k。 > **English:** Compute optimal size and k.

## 练习 2 — 计数布隆（困难）
用 4 位计数器支持删除操作。 > **English:** Implement a counting Bloom filter with deletion.

## 练习 3 — 真实应用（综合）
用布隆过滤器加速数据库查询的「不存在」判断。 > **English:** Use it to short-circuit absent lookups.

> **English:** Exercises are original variants of increasing difficulty, designed to extend the core lesson.
