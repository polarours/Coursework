## 需求概述 / Requirements

CSAPP 的 malloc lab 要求实现一个高性能的堆分配器（替换 `malloc`/`free`/`realloc`）。本项目实现最经典的基础版本：

CSAPP's malloc lab asks students to implement a heap allocator (replacing malloc/free/realloc). We build the classic baseline:

1. **隐式空闲链表 / Implicit free list**：块之间的边界由 header/footer 中的大小字段隐式给出，不额外存链表指针。
   *Block boundaries are encoded in header/footer size fields — no explicit pointers.*
2. **边界标签 / Boundary tags**：footer 让前一个块能被找到，实现 O(1) 向前合并。
   *Footers let us find the previous block for O(1) backward coalescing.*
3. **首次适应 / First-fit**：从头扫描，选第一个足够大的空闲块。
   *Scan from the start; pick the first free block that fits.*
4. **分割与合并 / Splitting & coalescing**：分配时分割剩余空间；释放时与相邻空闲块合并。
   *Split leftover space on alloc; merge with free neighbors on free.*

> **English:** Malloc lab is where systems students meet pointer arithmetic, alignment, and memory layout head-on. A single off-by-four can segfault the whole program — we hit exactly that (twice) during development.

## 输入与输出 / Input and output

- `mm_malloc(size)` 返回对齐的块指针；`mm_free(ptr)` 释放。
  *`mm_malloc(size)` returns an aligned pointer; `mm_free(ptr)` frees it.*
- 辅助函数 `count_free_blocks()` 返回当前空闲块数，用于验证合并。
  *A helper counts free blocks to verify coalescing in tests.*

## 边界条件 / Edge cases

- 第一个块没有前驱，最后一个块没有后继 → 合并时必须判断边界。
  *First block has no predecessor, last has no successor → coalesce must check boundaries.*
- payload 必须 8 字节对齐 → 堆起始偏移要小心。
  *Payload must be 8-byte aligned → heap start offset matters.*
- 大小不是 8 的倍数 → 向上取整（ALIGN）。
  *Non-multiple-of-8 sizes → round up.*

## 明确不做 / Non-goals

- 不实现显式空闲链表、分离空闲链表、伙伴系统等优化（见 07）。
  *No explicit lists, segregated lists, or buddy optimizations (see chapter 07).*

## 验收 / Acceptance

- [x] 三次 malloc 返回不重复、8 字节对齐的指针
- [x] 写入 payload 后数据不互相覆盖（A/B/C 验证）
- [x] free(a) → 2 个空闲块；free(b) 合并 → 仍 2 个；free(c) 全合并 → 1 个
- [x] 释放后再分配复用最低地址块（d == a）
