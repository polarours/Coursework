# 06 · 踩坑清单 / Pitfalls

## 1. 第一个块的 header 越界 / First block header out of bounds

- 症状 / Symptom：`extend_heap` 中段错误。
- 原因 / Cause：`HDRP(bp) = bp - 4`，若 bp 从 base 开始就写到 base 之前。
- 修复 / Fix：起始偏移 base + DSIZE，并放两个占位字。

> **English:** Classic malloc-lab trap #1. Always reserve padding before the first payload so header arithmetic stays in bounds.

## 2. 合并第一个/最后一个块 / Coalescing boundary blocks

- 症状 / Symptom：`coalesce` 中段错误（gdb 定位）。
- 原因 / Cause：第一个块没有前驱，`PREV_BLKP` 会回退到无效地址。
- 修复 / Fix：`is_first = (bp == heap_start)` 和 `at_end = (NEXT_BLKP(bp) >= brk_ptr)` 判断边界。

## 3. 对齐被起始偏移破坏 / Alignment broken by start offset

- 症状 / Symptom：地址结尾是 4（4 字节对齐，不是 8）。
- 原因 / Cause：偏移 WSIZE(4) 把 16 字节对齐的 base 变成 4 模 8。
- 修复 / Fix：偏移 DSIZE(8)。

## 4. 打印了失败却没断言 / Printing a failure without asserting

- 症状 / Symptom：输出显示 `aligned: 0` 但测试 PASS。
- 修复 / Fix：把对齐检查写成 `assert((unsigned long)a % 8 == 0)`。

## 5. footer 遗漏 / Missing footer update

- 症状 / Symptom：合并时读到错误的 size。
- 修复 / Fix：每次改 header 都同步改 footer（`PUT(FTRP(bp), PACK(size, alloc))`）。
