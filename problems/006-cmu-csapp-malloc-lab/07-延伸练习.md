# 07 · 延伸练习 / Follow-up exercises

## 练习 1 / Exercise 1 — realloc（中等）

实现 `mm_realloc(ptr, size)`：若新尺寸更小则原地缩小并分割；若更大则尝试与后继空闲块合并扩展，否则分配新块、拷贝数据、释放旧块。用真实测试验证数据不丢失。

提示 / Hint：注意 realloc 可能移动块；拷贝用 `memcpy`，长度取 min(旧可用大小, 新大小)。

> **English:** Implement realloc with in-place shrink/expand and fallback to allocate-copy-free. Verify no data loss with real payloads.

## 练习 2 / Exercise 2 — 显式空闲链表（困难）

在空闲块的 payload 区存 `prev`/`next` 指针，维护显式双向链表，把 find_fit 从 O(块数) 降到 O(空闲块数)；释放时按地址顺序插入链表。

提示 / Hint：空闲块至少需要 16 字节（两个指针）才能放下链表节点；注意与最小块大小的关系。

> **English:** Replace the implicit list with an explicit doubly linked free list. Measure the search-time improvement with a workload of many allocated blocks and few free ones.

## 练习 3 / Exercise 3 — 分离空闲链表（综合）

按大小等级（如 16、32、64、128…）维护多个空闲链表桶；分配时从合适桶取块，释放时放回对应桶。用 CSAPP 官方 driver（若可用）测吞吐率与利用率，与本基线对比。

提示 / Hint：桶索引可用 `size` 的最高位；合并跨桶时需要从对应桶中移除节点。

> **English:** Implement segregated free lists by size class. Compare throughput and utilization against the baseline allocator using measured data.
