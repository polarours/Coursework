# 03 · 逐步实现 / Step-by-step implementation

## 阶段 1 / Stage 1 — 块操作宏

用一组宏封装 header/footer 读写，避免到处写指针算术。

Macros encapsulate pointer arithmetic — essential for readability in C allocators.

```c
#define GET_SIZE(p)  (GET(p) & ~7)
#define GET_ALLOC(p) (GET(p) & 1)
#define HDRP(bp)     ((unsigned char *)(bp) - WSIZE)
#define FTRP(bp)     ((unsigned char *)(bp) + GET_SIZE(HDRP(bp)) - DSIZE)
#define NEXT_BLKP(bp)((unsigned char *)(bp) + GET_SIZE(HDRP(bp)))
```

## 阶段 2 / Stage 2 — 初始化与扩展

`mm_init` 的两个占位字保证对齐；`extend_heap` 申请 CHUNKSIZE（4096）的大块。

Two padding words in `mm_init` guarantee alignment; `extend_heap` grabs a 4KB chunk.

```c
heap_start = base + DSIZE;   /* 8 字节对齐 + 不越界 */
PUT(base, 0); PUT(base + WSIZE, 0);
```

验证 / Verify: 第一次 malloc 前堆里 1 个空闲块。

## 阶段 3 / Stage 3 — 查找与分割

`find_fit` 首次适应；`place` 若剩余 ≥ 2×DSIZE 则分割。

First-fit search; split if leftover ≥ 16 bytes.

```c
if (csize - asize >= (2 * DSIZE)) { /* 分割 / split */ }
```

验证 / Verify: 三次 malloc 得到地址 0x...068、0x...088、0x...0a8（间隔 0x20 = 32 字节）。

## 阶段 4 / Stage 4 — 释放与合并

四种情况：前后都占用、仅后空、仅前空、前后都空。

Four cases: both neighbors allocated, only next free, only prev free, both free.

```c
int is_first = (bp == heap_start);
size_t prev_alloc = is_first ? 1 : GET_ALLOC(FTRP(PREV_BLKP(bp)));
int at_end = (NEXT_BLKP(bp) >= brk_ptr);
size_t next_alloc = at_end ? 1 : GET_ALLOC(HDRP(NEXT_BLKP(bp)));
```

验证 / Verify: free 后空闲块数 2 → 2（合并）→ 1（全合并）。

## 阶段 5 / Stage 5 — 测试验证

编译运行 harness，检查对齐、数据隔离、合并、复用。

Compile and run the harness; check alignment, data isolation, coalescing, reuse.

验证 / Verify: `ALL TESTS PASSED`。

> **English:** Five stages: pointer-arithmetic macros, heap init and extension, first-fit with splitting, four-case boundary-tag coalescing, and harness verification. The three returned pointers are spaced 0x20 (32 bytes = 8-byte header + 24-byte payload) apart, which confirms the block layout.
