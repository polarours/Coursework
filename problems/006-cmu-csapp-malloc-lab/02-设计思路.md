# 02 · 设计思路 / Design rationale

## 整体架构 / Architecture

```text
 初始堆（扩展 4096 字节）:
 ┌──────┬──────────────────────────────┐
 │header│ 4096 字节空闲 payload         │footer│
 └──────┴──────────────────────────────┘
 malloc(24) 后（分割）:
 ┌──────┬────────┬──────┬──────────────────┐
 │32|1  │ 24B    │32|0  │ remaining        │
 │header│ a      │footer│ free block       │
 └──────┴────────┴──────┴──────────────────┘
```

每块格式 / Block format: `[4B header | payload | 4B footer]`，header/footer = `size | alloc_bit`。

> **English:** The elegance of implicit lists: the size in the header tells you where the next block starts, and the size in the footer tells you where the previous block starts. Two integers replace an entire linked-list structure.

## 关键决策 / Key decisions

| 决策 / Decision | 选择 / Choice | 理由 / Why |
|---|---|---|
| 空闲链表 / Free list | 隐式（用大小字段隐式链接）| 实现最简单，适合教学 / simplest for teaching |
| 合并 / Coalesce | 边界标签，四种情况 | O(1) 判断前后块是否空闲 / O(1) neighbor checks |
| 查找 / Search | 首次适应 | 简单；性能不如分离空闲链表但够用 / simple baseline |
| 对齐 / Alignment | 8 字节（DSIZE）| CSAPP 标准；x86-64 通用 / CSAPP standard |
| 堆起始偏移 / Heap offset | base + 8（两个占位字）| 保证 payload 8 字节对齐且不越界 / alignment + no out-of-bounds |

## 备选方案 / Alternatives

- **显式空闲链表**：空闲块里存 prev/next 指针，查找更快但实现复杂。
  *Explicit pointers make search faster but add complexity — see exercise 07.*
- **分离空闲链表**：按大小分桶，接近真实 malloc；教学版先掌握基础。
  *Segregated lists approach real malloc; learn the baseline first.*

> **English:** The three real bugs we hit (start offset, boundary coalescing, alignment) are exactly the classic malloc-lab traps. Reading chapter 05's failure table is as valuable as reading the code.
