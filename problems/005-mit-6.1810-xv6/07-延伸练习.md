# 07 · 延伸练习 / Follow-up exercises

## 练习 1 / Exercise 1 — SJF 与响应时间（中等）

实现最短作业优先（SJF）与非抢占式优先级调度；与本项目的 FCFS/RR/MLFQ 对比平均等待、平均响应时间和公平性指标（如等待时间方差）。

提示 / Hint：用相同的 3 进程 workload，保证对比公平；响应时间 = 首次调度时刻 - 到达时刻。

> **English:** Implement SJF and priority scheduling, then compare all five algorithms on wait time, response time, and fairness (variance of wait times). Explain the trade-offs with your numbers.

## 练习 2 / Exercise 2 — Copy-on-Write fork（困难）

在模拟器中实现 COW fork：父子进程初始共享物理页（页表项标记为只读），任一进程写入时触发缺页异常，复制该页后再写。统计复制次数与节省的内存。

提示 / Hint：用字典模拟页表 `pid -> {vaddr: (paddr, readonly)}`；写操作检查 readonly 并复制。

> **English:** Simulate copy-on-write fork with page tables. Count page faults and pages copied; compare memory usage with eager copy.

## 练习 3 / Exercise 3 — 真实 xv6 lab（综合）

在 QEMU 中启动 xv6，完成官方 `util` 与 `syscall` lab（实现 `trace`、`sysinfo`）；把真实内核里的调度与内存管理与本模拟器对照，写一页对比笔记。

提示 / Hint：xv6 源码与实验说明见课程主页；注意在 Linux 上需要 `qemu-system-riscv64` 与交叉编译工具链。

> **English:** Run real xv6 in QEMU and complete the official util/syscall labs. Write a comparison note between the real kernel's mechanisms and this simulator.
