# 07 · 延伸练习 / Extensions

## 1. corners_heuristic 升级：贪心链上界取 min / a stronger admissible bound

max 版保守（corners-tiny 1050 节点）。经典 CS188 满分做法：对未访问角做**贪心最近角链**（一条真实可行路径 → 是**上界**），再与各角 max 下界取 min——可采纳且紧得多。实测对比两版在 corners-medium 的展开数差。

## 2. UCS 的 stay-east / stay-west 代价函数

框架自带 `stay_east_cost_function` / `stay_west_cost_function`（列号敏感代价）。跑 `--agent-arg 0::problem-cost=<alias>` 观察 UCS 与 BFS 的 turns 分道扬镳——**cost 敏感性**的直接演示。

## 3. 一致性 (consistency) 的意义

corners_h 的 max 版是否 consistent？构造一个反例或证明之；再换贪心链版对比 A* 的 graph-search 重开次数（在 best_g 逻辑里加计数器）。

## 4. ApproximateSearchAgent 的质量分

贪心 165 步 vs 全局最优多少？用 FoodSearchProblem + A* 在 search-medium 上求真最优（状态空间大，可能要跑很久或加更强启发式）——得出贪心近似比，对照 CS188 的评分阈值（如 ≤1.5×最优）。

## 5. pacai 的职业化测试基建

框架自带 `pacai/test/`（unittest 式 + JSON testdata 回放）。给 032 的 run.sh 加一层直接调用框架测试跑 student 模块——把"本地验证"升级为"框架原生验证"。
