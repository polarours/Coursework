# 05 · 调试与测试 / Debugging & testing

## 测试形态 / Harness

官方 autograder 不公开（课程服务器）。本地验证三板斧：

1. **venv 自举**：`~/.local/share/pacai-venv` 装 Pillow + edq-utils（PEP 668 拦截系统 pip，venv 是干净解）
2. **构建副本树**：`cp -r upstream /tmp/...` 后替换 `student/singlesearch.py`——upstream 一个字节不动
3. **用例矩阵**：board 与问题**配对**（见下），断言 `Record: Win` + `Path found` 的 steps/cost

## board 配对表（关键发现）/ The board↔problem pairing (a real finding)

| board | 正确用法 | 误用后果 |
|---|---|---|
| maze-*（有 search_target） | PositionSearchProblem | — |
| search-*（无 target，满地食物） | Food / ClosestDot / Approximate | position 搜索到达 (1,1) 后 agent 停住，**游戏永不结束** |
| corners-* | CornersSearchProblem | — |

误配的直接观测：search-medium + position BFS 找到 25 步路径后 60s 超时无终局——win 条件是"吃光食物"，不是"到 (1,1)"。
