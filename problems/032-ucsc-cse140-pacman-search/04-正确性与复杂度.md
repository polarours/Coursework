# 04 · 正确性与复杂度 / Correctness & complexity

## 可采纳性证明 / Admissibility argument

**corners_heuristic**：设剩余未访问角集合 C，任意从当前状态完成的路径 π 必须访问每个 c ∈ C。π 的长度 ≥ dist(pos, c)（π 到 c 之前可能绕路，绕路不减长度），对**每个** c 成立 → |π| ≥ max_c dist(pos, c) = h。故 h 可采纳，A* 最优性保持。

> **English:** A completing path must reach every remaining corner, so its length dominates each direct distance, hence their max — admissible by domination.

**food_heuristic** 同构论证（剩余食物代替角）。

## 复杂度 / Complexity

| 求解器 | 时间 | 空间 | 备注 |
|---|---|---|---|
| DFS | O(b^m) | O(b·m) | 不最优 |
| BFS | O(b^d) | O(b^d) | 最优（unit cost） |
| UCS | 最优 | — | lazy deletion |
| A* | 最优 + 展开数 ≤ UCS | — | h 有效性决定剪枝 |

**实测**（corners-tiny，cost 同为 28）：null 展开 **1449** 节点 → corners_h **1050** 节点；maze-tiny 上 A*（曼哈顿）展开 14 < BFS 16。启发式收益全部来自真实运行日志。

## 交叉验证 / Cross-verification

BFS/UCS/A* 在 maze-tiny 的 cost **三者一致 = 8.00**（最优性互证），DFS = 10（次优但有效）。跑在 05 章的 run.sh 末尾固化。
