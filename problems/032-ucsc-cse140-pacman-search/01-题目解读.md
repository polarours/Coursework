## 需求概述 / Requirements

CSE140 p1（题面在 031 upstream 的 `p1/README.md`，25 分制）：Pacman 要学会在迷宫里**找路**与**收集食物**。框架是 pacai v2.1.0（edulinq 维护的 CS188 开源重制），作业只提交一个文件 `pacai/student/singlesearch.py`，8 处 `NotImplementedError`：

CSE140 p1: teach Pacman to find paths and collect food. Framework is pacai v2.1.0; the sole submission file is `singlesearch.py` with eight stubs:

1. **四求解器 / four solvers**：`depth_first_search`、`breadth_first_search`、`uniform_cost_search`、`astar_search`——统一签名 `(problem, heuristic, rng) -> SearchSolution`
2. **四角问题 / corners**：`CornersSearchNode`（状态设计自由）、`CornersSearchProblem`（起点/目标/后继三法）、`corners_heuristic`（须可采纳）
3. **食物启发 / food**：`food_heuristic`（对 `FoodSearchNode` 可采纳）
4. **贪心 agent / greedy**：`ClosestDotSearchAgent`（复用 `GreedySubproblemSearchAgent`）
5. **目标判定 / any-marker**：`AnyMarkerSearchProblem.is_goal_node`
6. **近似搜索 / approximate**：`ApproximateSearchAgent`（suboptimal 即可）

> **English:** The eight stubs are the statement: four solvers, a state-design problem, two admissible heuristics, a greedy agent, one goal predicate, and one approximate agent.

## 边界条件 / Edge cases

- 不可达目标 → 抛 `SolutionNotFoundError`（框架自带类型）
- Corners 状态必须含"当前位置 + 四角访问标记"，否则搜索空间爆炸
- 启发式**必须可采纳**（不高估），否则 A* 失去最优性保证

## 验收 / Acceptance

- [x] maze-tiny 四求解器全 Win；BFS/UCS/A* cost 一致 = 8（最优性交叉）
- [x] corners-tiny/medium A* + corners_h 全 Win（28/106 步）
- [x] search-tiny A* + food_h Win（27 步）
- [x] search-medium ClosestDot 与 Approximate Win（165 步）
