# 05 · 调试与测试 / Debugging and testing

## 真实输出 / Real output

```text
[shell] [Command(['cat', 'input.txt'], ...), Command(['grep', 'hello'], ..., out=out.txt)]
[shell] [Command(['echo', 'hello world'], ..., out=log.txt, append=True)]
[shell] [Command(['echo', '/home/user'], ...)]
--- PASS: test_shell
ALL TESTS PASSED
```

## 输出解读 / Reading the output

三级管道 `wc -l < a.txt | sort | uniq > result.txt` 正确解析为 3 个命令；引号内的空格保持为单个参数。

| 症状 | 原因 | 修复 |
|---|---|---|
| LSP 类型报错 | 属性初始为 None 注解推断过窄 | 显式 `str | None` 注解 |
