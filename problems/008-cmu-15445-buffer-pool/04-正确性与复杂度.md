# 04 · 正确性与复杂度 / Correctness and complexity

## 不变量 / Invariants

1. page_table 中的每个 page_id 指向的 frame，其 page_id 字段反向一致。
2. pin_count>0 的页永远不会被 _free_frame。
3. 脏页被淘汰前一定写回磁盘。

> **English:** Invariant 2 is what the pin-protection test verifies (pinned page survived 6 allocations).

## 复杂度 / Complexity

| 操作 / Operation | 时间 / Time |
|---|---|
| fetch_page（命中）/ hit | O(1) |
| new_page / fetch（需淘汰）/ with eviction | O(页框数) / O(frames) |
| flush | O(页大小) |
