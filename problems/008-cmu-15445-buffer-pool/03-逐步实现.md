# 03 · 逐步实现 / Step-by-step implementation

## 阶段 1 / Stage 1 — 数据结构

`Frame(index, page_id, pin_count, dirty, data)`；`page_table` 映射；`OrderedDict` 做 LRU。

## 阶段 2 / Stage 2 — new_page / fetch_page

新页：找 victim → 清空 → 置脏 → pin=1。取页：命中 pin++；未命中从磁盘读入。

```python
frame = self._find_victim()
self._free_frame(frame)
frame.page_id = page_id
frame.pin_count = 1
```

验证 / Verify: 分配 0/1/2，池满（frames_used=3）。

## 阶段 3 / Stage 3 — LRU 淘汰

访问 p0 后 LRU 顺序变为 `[1, 2, 0]`；新分配淘汰 p1。

验证 / Verify: p1 不在 page_table，p0/p2 保留。

## 阶段 4 / Stage 4 — 写回与 pin 保护

```python
if frame.dirty:
    self.disk.write(frame.page_id, frame.data)
```

验证 / Verify: flush(p0) 后磁盘含 p0 且数据一致；pin 住的 p0 经历 6 次分配仍在。

> **English:** The pin-protection test is the most important: it directly verifies that `_find_victim` skips pinned frames.
