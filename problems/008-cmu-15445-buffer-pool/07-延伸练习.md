# 07 · 延伸练习 / Follow-up exercises

## 练习 1 / Exercise 1 — Clock 替换（中等）
实现时钟（二次机会）算法替代 LRU，对比相同访问序列下的淘汰次数。
> **English:** Implement clock replacement and compare eviction counts with LRU.

## 练习 2 / Exercise 2 — B+ 树索引（困难）
实现简化的 B+ 树（插入、查找、范围查询），页节点通过 buffer pool 访问。
> **English:** Build a simplified B+ tree whose nodes live in the buffer pool.

## 练习 3 / Exercise 3 — 并发缓冲池（综合）
加入读写锁，使 fetch/unpin 线程安全；用多线程压力测试验证无竞争。
> **English:** Make the buffer pool thread-safe with latches; stress-test with concurrent threads.
