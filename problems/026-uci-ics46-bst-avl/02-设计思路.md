# 02 · 设计思路 / Design

## 基类承担接口，子类只写策略 / Base holds interface, subclass writes strategy

`BST` 定公共方法与 count 维护；`BSTree`/`AVLTree` 只实现**插入节点路径**上的差异：普通 BST 直插；AVL 插入后沿回溯路径更新高度并旋转。公共接口统一维护 `count`（见 06 的坑 2）。

> **English:** The base class owns the interface and the counter; each subclass contributes only its insertion policy — classic template method without the virtual-call noise.

## AVL 的四个旋转 / The four rotations

LL → 右旋；RR → 左旋；LR → 先左后右；RL → 先右后左。判据写在回溯点：`balance = h(left) - h(right)`，`|balance| > 1` 时按子节点偏向选旋转。

## 高度缓存 / Cached heights

`Node` 带 `height` 字段，插入/删除回溯时 O(1) 更新——否则每次平衡判断都要 O(n) 递归求高，AVL 的 O(log n) 承诺直接破产。
*Heights are cached on the nodes; recomputing them per balance check would void the O(log n) promise.*
