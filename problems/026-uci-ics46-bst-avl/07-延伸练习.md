# 07 · 延伸练习 / Extensions

## 1. 旋转次数统计 / Counting rotations

给 AVL 加静态计数器：随机/有序/逆序三种输入下统计旋转次数分布——验证"有序输入旋转最多、随机输入偶发"的直觉。

## 2. 删除的全套语义 / Full removal semantics

BST 删除的三分支（叶/单子/双子，双子找中序后继）与 AVL 删除的**向上连续旋转**（删除可触发根到叶路径上多次再平衡）——测试删除后再插大量随机键的树高稳定性。

## 3. 红黑树对照 / Red-black for contrast

实现红黑树跑同一批官方数据：高度比 AVL 略高但旋转更少（变色为主）——用 measure_BSTs 的输出格式做三方对比报告。

## 4. 迭代器与中序遍历

给 BST 基类加 `begin()/end()`（显式栈模拟中序）：range-for 直接按键序遍历树，与 024/025 的数组/链表迭代器凑齐三种经典结构。
