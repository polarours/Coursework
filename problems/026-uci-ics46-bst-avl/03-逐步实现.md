## 2. 计数归公共接口 / Counting in the public interface

```cpp
bool BSTree::insert(const std::string &key) {
    if (find_node(root, key) != nullptr) return false;  // 先判重
    root = insert_node(root, key);
    ++count;   // 计数在非静态上下文里维护
    return true;
}
```

static 工具函数（insert_node/delete_node）只管结构与高度；存在性与计数由公共方法裁决——**判重一次查询，语义清晰**。

```cpp
Node * AVLTree::insert_node(Node *node, const std::string &key) {
    if (node == nullptr) { update_count(+1); return new Node(key); }
    // ...常规二分下行...
    node->height = 1 + std::max(h(node->left), h(node->right));

}
```
