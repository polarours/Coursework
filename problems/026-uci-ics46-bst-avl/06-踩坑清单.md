# 06 · 踩坑清单 / Pitfalls

## 1. 字典序 ≠ 数值序 / Lexicographic ≠ numeric

- 想让 BST 退化成完美链，用 `w0..w1023` 顺序插入？**不行**：`"w10" < "w2"`（字典序比首字符），序列根本不严格递增，第一版测试因此失败。
- 修复：零填充 `w%04d`（w0000..w1023），字典序=数值序，链高恰好 1024。
  *Zero-pad your keys: lexicographic order equals numeric order only for fixed widths.*

## 2. static 与非静态的边界 / The static boundary

- `insert_node/delete_node` 是 static（官方 starter 设计）：函数体里维护 `count` 编译不过。**状态归对象，算法归函数**——计数、根指针全留在公共接口层。

## 3. 全局类型的类外定义 / Out-of-class definitions of global types

- `BSTree::Node *` 隐含"Node 是 BSTree 的嵌套类"的假设——见 03 章 1。

## 4. 相对路径的 demo / The relative-path demo

- main.cpp 读 `src/*.txt`，必须在 `upstream/` 目录下跑——测试脚本 `cd upstream` 后再执行。

## 5. 高度缓存的失效窗口 / Stale cached heights

- 旋转之后子树根变化，忘更新旋转产物的 height 会让后续平衡判据全错——旋转函数的收尾三行（更新两个子节点+自身高度）必须成套。
