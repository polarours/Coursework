## 3. determinant：按第一行余子式展开

```cpp
double determinant(const Matrix& matrix) {
    if (matrix.empty()) return 1.0;              // 空积约定
    if (matrix.size() == 1) return matrix[0][0];
    double det = 0;
    for (std::size_t j = 0; j < matrix[0].size(); ++j)
        det += std::pow(-1, j) * matrix[0][j]
             * determinant(minor(matrix, 0, j));
    return det;
}
```

## 4. upper_triangular：不许选主元

首主元为 0 时，**向下找一行加到第 0 行**使其非零，再正常消元——swap 在本题语义里不合法（测试的 bonus 分支）。
*When the pivot is zero, add a suitable lower row onto row 0 instead of swapping — the tests forbid pivoting.*
