# 07 · 延伸练习 / Extensions

## 1. LU 分解版 determinant / LU-based determinant

把余子式递归换成 LU 分解：det = 对角乘积 × 置换符号。4×4 以上快几个数量级；顺带验证分解后行列式与原实现一致。

## 2. `concatenate` 的语义补全

axis=0 行拼接要求列数一致，axis=1 列拼接要求行数一致——不一致抛什么？官方测试没覆盖，**你来定语义并补测试**（UMD 式"没写的规格自己定"）。

## 3. 逆矩阵的数值稳定性

对病态矩阵（如 Hilbert 4×4）比较伴随法与 Gauss-Jordan 法的误差——教学库与数值库的鸿沟在哪？

## 4. 静态断言矩阵类型

`using Matrix = std::vector<std::vector<double>>` 不保证"方阵"与"非锯齿"。设计一个 `struct Matrix { ... }` 包装类，把形状检查移进类型系统。
