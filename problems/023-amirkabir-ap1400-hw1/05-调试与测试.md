upstream 的 `HW1/src/unit_test.cpp` 被 `/* ... */` 整体注释。处理方式：生成**注释剥离副本** `tests/unit_test_active.cpp`（预处理去 `/* */` 外壳），原文件原样保留。本机 gtest 1.18 要求 C++17（原作业按 C++14 写），编译参数如实注明。

```
    -lgtest -lgtest_main -pthread
→ [  PASSED  ] 24 tests
```

## 六处真实语义修复实录 / Six real semantic fixes

对照官方测试逐条跑、逐条修，**每一处都是第一版实现的真实错误**：

1. `random(min>max)` 必须抛 `std::logic_error`——第一版直接构造 distribution，min>max 时崩溃
2. 空矩阵相乘返回 `{}`；维度不匹配抛 `logic_error`——第一版访问 `b[0]` 越界
3. `determinant({})` = 1.0——第一版返回 0.0（数学空积约定）
4. `inverse` 奇异矩阵抛 `logic_error`——第一版抛 `runtime_error`（类型都错）
5. `ero_sum(a, r1, c, r2)` 语义是 row_r2 += c × row_r1——第一版方向写反
6. `upper_triangular` 不允许换主元——bonus 测试首主元为 0，须用行加法绕开

> **English:** All six were caught by reading the official suite as spec; none were invented.
