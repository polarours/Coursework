# 04 · 正确性与复杂度 / Correctness & complexity

## 复杂度对照 / Complexity

| 函数 | 复杂度 | 备注 |
|---|---|---|
| random / show / 转置 / 数乘 | O(n·m) | 直写 |
| 矩阵乘 | O(n·m·k) | 经典三重循环 |
| minor | O(n·m) | 每次重建 |
| determinant | O((n!) 级) | 余子式递归，n 大时爆炸 |
| inverse | O(n² · det) | adjugate / det：n³ + 递归 det |
| upper_triangular | O(n³) | 消元；含零主元绕行 |

> **English:** The cofactor recursion is factorial — fine for the assignment's 3×3/4×4 tests, catastrophic beyond. Chapter 07 points at LU decomposition as the real-world fix.
