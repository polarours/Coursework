# 06 · 踩坑清单 / Pitfalls

## 1. `std::uniform_real_distribution(min, max)` 的静默前提

- distribution 构造要求 min ≤ max，违反是 UB（libc++ 直接断言崩溃）——**参数校验必须在构造前**。

## 2. 余子式方向 & 符号 / Cofactor sign

- `std::pow(-1, j)` 用整数幂最稳；浮点 pow(-1.0, 3) 在个别平台出 -0.999... 的坑。

## 3. 抛错类型要对号 / Throw the right type

- 官方测试用 `EXPECT_THROW(..., std::logic_error)`：参数/维度类错误是**逻辑错误**，抛 `runtime_error` 就是不合格——第一版在第 4 处就栽在这里。

## 4. 原测试整体注释 / The commented-out suite

- upstream 测试整体在 `/* */` 里。**不改原文件**（submodule 保持原貌）——生成激活副本编译，报告里注明来源。
  *Generate an uncommented copy; never touch the upstream submodule.*

## 5. gtest 版本代差 / gtest generation gap

- 原作业按 C++14 写，本机 gtest 1.18 头文件要求 C++17——`-std=c++17` 是环境适配，不是作业现代化。
