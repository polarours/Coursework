Amirkabir AP1400-2 HW1: a 17-function matrix algebra library in namespace `algebra`, with `std::vector<std::vector<double>>` as the matrix type:

> **English:** Every signature and edge semantic is pinned by a 24-case gtest suite — including which exception type to throw and the mathematical convention det({}) = 1.

## 边界条件 / Edge cases（官方测试明确要求）

- `random` 的 min > max → 抛 `std::logic_error`（不是悄悄交换）
- 空矩阵乘空矩阵 → 返回 `{}`；维度不匹配 → 抛 `logic_error`
- `determinant({})` = 1.0（空积的数学约定）
- 奇异矩阵 `inverse` → 抛 `logic_error`
- `upper_triangular` **不允许**换行找主元（bonus 测试专门卡这个）
