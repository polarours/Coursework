# 07 · 延伸练习 / Extensions

## 1. N-Queens 解的计数与全解枚举 / Count all solutions

改返回值为解计数器：8-Queens 应得 **92** 个解（已知答案，可自查）；对比剪枝前后访问结点数。

## 2. Sudoku 的 MRV 启发式 / Minimum remaining values

候选最少的空格先填：改"第一个空格"为"候选最少格"，实测三档难度的时间变化——hard 档提升最明显。

## 3. Sujiko 的约束传播

把宫目标和转为**上下界传播**：每格可选数字由所在各宫剩余容量约束——写成传播函数后，回溯几乎不需要。

## 4. 三题统一求解器 / One solver to rule them

把三题抽象成 `Problem { candidates(), choose(), unchoose(), complete() }` 接口，写一个通用 `backtrack(Problem)`——检验你对骨架的理解是否真的结构化（而非三份复制粘贴）。
