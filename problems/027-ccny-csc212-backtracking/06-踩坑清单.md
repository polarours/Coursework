# 06 · 踩坑清单 / Pitfalls

## 1. 路径里的空格 / Spaces in the path

- `Labs/Lab 07 Backtracking/...` 编译时 `-I` 参数必须整段加引号，否则 bash 按空格切词——症状是"头文件找不到"。

## 2. 数独的"本格无解"≠"全局无解" / Local dead-end vs global

- 某空格 1..9 全试完：直接 `return false` 把失败上抛给上一个 choose 点——**不要**继续扫后面的空格（后面的格子是在错误前提下白费功夫）。

## 3. Sujiko 预填格被覆盖 / Don't clobber prefilled cells

- 递进下标时跳过非 EMPTY 格；忘记跳过会"解出"一个篡改了题面的假解。

## 4. 剪枝的正确性边界 / Prune only what must fail

- "部分和 ≥ 目标"可砍（必然失败）；"部分和 < 目标"不可砍（可能补上）——剪错方向会把真解剪掉，表现为"有解却报无解"。

## 5. is_valid_row 只查左半边 / The half-plane check

- starter 的 is_valid_row 只查**已放置侧**（col 以左）——因为递归按列推进，右侧还没放皇后。理解这个前提才能放心复用 starter 代码。
