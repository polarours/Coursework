# 03 · 逐步实现 / Step-by-step implementation

## 1. N-Queens：starter 已给 is_valid_row，只写主体

```cpp
bool NQueens::solve_rec(int col) {
    if (col >= (int)board_size) return true;          // 全部列已放
    for (unsigned int row = 0; row < board_size; ++row) {
        if (is_valid_row(row, col)) {
            (*board)[row][col] = 1;                   // choose
            if (solve_rec(col + 1)) return true;
            (*board)[row][col] = 0;                   // unchoose
        }
    }
    return false;
}
```

**为什么按列推进** / *Why column-by-column*: 每列恰好一皇后，行/对角冲突交给 is_valid_row 检查——候选空间从 n^(n²) 缩到 n^n，再被合法性剪到可控。

## 2. Sudoku：找第一个空格，试 1..9

```cpp
bool Sudoku::solve() {
    for (row...) for (col...)
        if (board[row][col] == EMPTY) {
            for (int num = 1; num <= 9; ++num)
                if (is_valid(row, col, num)) {
                    board[row][col] = num;            // choose
                    if (solve()) return true;
                    board[row][col] = EMPTY;          // unchoose
                }
            return false;   // 本格无解 → 整体回溯
        }
    return true;           // 无空格 → 完成
}
```
