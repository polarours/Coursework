# 02 · 设计思路 / Design

## 回溯的统一骨架 / One backtracking skeleton

```text
solve(state):
    if 完成: return true
    for 每个候选 c:
        if 合法(c):
            放置 c
            if solve(state'): return true
            撤销 c        ← 回溯的本体
    return false
```

三题全部套进这个骨架：N-Queens 按列推进（候选=行）、Sudoku 找第一个空格（候选=1..9）、Sujiko 按线性下标推进（候选=未用数字）。

> **English:** One skeleton, three instantiations: candidates are rows, digits, or unused numbers; the unchoose step is the whole trick.

## Sujiko 的两个剪枝 / Two prunes for Sujiko

1. **唯一性剪枝**：每个数字只用一次——放前查全盘
2. **目标和剪枝**：一个 2×2 宫填满 3 格时若部分和已 ≥ 目标，直接砍——不等第 4 格填完才失败
   *Prune as soon as a three-of-four partial sum reaches the target; don't wait for the fourth cell.*

剪枝的正确性边界要小心：**只能砍必然失败的分支**，"部分和已达目标"必然失败（剩余格 ≥1 只会更大），但"部分和 < 目标"不能砍（后面还可能补上）。
