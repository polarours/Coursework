## 需求概述 / Requirements

UC Irvine ECS36C（数据结构，Python 转 C++ 课程）HW1：三个模板容器——`LinkedList<T>`、`Stack<T>`、`Queue<T>`。重点在**现代 C++ 的表达方式**：

UC Irvine ECS36C HW1: three templated containers — LinkedList, Stack, Queue — with the emphasis on modern C++ idioms:

1. `LinkedList<T>`：头尾双指针、`find/prepend/append`、**移动构造**、`std::vector` 构造
2. `Stack<T>`：`push/pop/top`，**空栈 pop 返回 `std::optional<T>` 的 `nullopt`**（不崩溃）
3. `Queue<T>`：`enqueue/dequeue/front`，同样 optional 语义
4. 构造语义：`Stack<int> s({1,2,3})` 中**末尾元素是栈顶**（"end of items is the top"）

> **English:** The modern-C++ tell: empty-pop returns `std::optional<T>`::nullopt instead of crashing or returning a sentinel — the interface itself teaches safer container design.

## 边界条件 / Edge cases

- 空容器：`top()`/`pop()` 返回 `nullopt`，`size()` 为 0
- vector 构造：尾元素即栈顶 / 队尾
- `find` 未命中返回 `nullptr`
