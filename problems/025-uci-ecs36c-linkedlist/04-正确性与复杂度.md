# 04 · 正确性与复杂度 / Correctness & complexity

| 操作 | 复杂度 | 说明 |
|---|---|---|
| prepend / append | O(1) | 头/尾直插 |
| find | O(n) | 线性扫描 |
| push/pop (Stack) | O(1) | 单端 |
| enqueue/dequeue (Queue) | O(1) | 尾进头出 |
| 移动构造 | O(1) | 三指针交接 |

> **English:** Everything is O(1) except find — the head/tail pair makes both ends cheap, which is exactly why a queue needs a list with a tail.
