# 06 · 踩坑清单 / Pitfalls

## 1. 模板实现放 .cpp 的包含式编译 / Templates in .cpp

- 模板必须**实例化点可见**：实现放 .cpp 时要么显式实例化，要么被直接 include（本题走 include 路线）——include 顺序错会得到一堆 linker 错误。

## 2. 移动构造忘置空 / Move without nulling

- 被偷对象不置空 → 析构双删。`other._head = nullptr;` 一行保平安。

## 3. optional 的比较 / Comparing optionals

- `stack.pop() == std::nullopt` 是合法断言；但 `*stack.pop()` 在空栈上是 UB——先判 has_value 再取值。

## 4. 官方测试的注释态 / Commented-out official tests

- upstream tests/ 的官方用例是注释态发放。同 023 的纪律：生成激活副本、不改原文件、README 注明来源。

## 5. "end of items is the top" 的方向性 / The direction convention

- vector 构造的栈顶是**末元素**，写反（push 进头）不会挂大部分测试，只有方向性断言能抓住——语义测试必须显式锁方向。
