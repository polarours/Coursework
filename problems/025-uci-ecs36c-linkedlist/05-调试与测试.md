# 05 · 调试与测试 / Debugging & testing

## 测试来源分层 / Layered test provenance

```
== LinkedList tests (upstream official) ==   ← upstream/tests/LinkedListTest.cpp 原样编译
== Stack/Queue tests ==                       ← 官方注释示例激活 + 接口语义补全
```

第一层不动 upstream 原文件直接编译；第二层把官方示例用例从注释里解放，再加语义测试（pop 到空、vector 方向）。

## 实测记录 / Verified runs

- upstream 官方 LinkedList 测试通过
- Stack: LIFO 序 3→2→1、空 pop = nullopt、vector 构造 top==3 全部通过
- Queue: FIFO 序与空 dequeue 同样通过

## 开发实录 / Development log

- 无重大返工；本题的实现路径基本是"顺着接口写"，难点全在**测试编排**（include 顺序、注释激活）
  *The code came easily; the harness was the puzzle — include ordering and comment activation.*
