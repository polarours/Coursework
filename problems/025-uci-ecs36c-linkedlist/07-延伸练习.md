# 07 · 延伸练习 / Extensions

## 1. 析构与 clear

本题 starter 未要求析构（教学简化）。补 `~LinkedList()`：逐节点释放，再写 valgrind 验证零泄漏——与 024 的 AList 析构对照。

## 2. 拷贝赋值运算符

只有移动构造的容器是"半成品"：补拷贝构造 + `operator=`（copy-and-swap），测试三/五法则（Rule of Three/Five）齐套。

## 3. 反向迭代器

给 LinkedList 加 `rbegin()/rend()`（从 _tail 走回 _head 需要双向节点——把单向改双向，评估改动半径）。与 029 的双向环形哨兵链表互相印证。

## 4. 用 optional 重构 028

Clemson 028 的空栈语义是"返回 T()"（C++98 风格）；用本题的 optional 语义重构它，跑 028 的官方样例测试看哪些行为升级了——两个真实作业之间的语义演进实验。
