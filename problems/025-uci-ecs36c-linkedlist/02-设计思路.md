# 02 · 设计思路 / Design

## 尾指针：让 append O(1) / Tail pointer: O(1) append

只有头指针的单链表 append 是 O(n)（每次走到尾）。加一个 `_tail`：append 直连尾节点；prepend 改头指针；**空表是唯一要同时维护两端的情形**。

> **English:** One extra pointer buys O(1) append; the empty list is the only case where both pointers must be wired by hand.

## 移动构造：偷指针而不是复制 / Move ctor: steal, don't copy

```cpp
LinkedList(LinkedList<T> &&other) : _size(other._size), _head(other._head), _tail(other._tail) {
    other._size = 0; other._head = nullptr; other._tail = nullptr;
}
```

三根指针搬走，把源头置空——被偷的对象处于"有效但未定"状态，析构安全。**为什么必须置空** / *Why null out the source*: 两对象析构同一串节点 = double free。

## optional 语义：把错误编码进类型 / Encoding errors into the type

空栈 pop 的三种设计：崩溃（断言）、哨兵值（T() 不可靠）、`std::optional`（显式表达"可能没有"）。ECS36C 选第三种——学生第一次体会到**接口设计**也是作业的一部分。

## friend 与封装 / friend and encapsulation

`LinkedListNode` 的构造与 `_next` 为私有，`LinkedList` 以 friend 访问——节点不变式（只有链表能接线）由类型系统保证。
