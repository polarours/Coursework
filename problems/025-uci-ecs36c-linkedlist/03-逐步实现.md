# 03 · 逐步实现 / Step-by-step implementation

## 1. 节点与 find

```cpp
LinkedListNode<T> *LinkedList<T>::find(T value) const {
    for (LinkedListNode<T> *cur = _head; cur != nullptr; cur = cur->next())
        if (cur->value == value) return cur;
    return nullptr;
}
```

## 2. append：空表分岔 / append: the empty-list fork

```cpp
LinkedListNode<T> *LinkedList<T>::append(T value) {
    LinkedListNode<T> *node = new LinkedListNode<T>(value);
    if (_tail == nullptr) { _head = _tail = node; }   // 空表：两端同接
    else { _tail->_next = node; _tail = node; }
    ++_size;
    return node;
}
```

## 3. Stack：vector 构造的方向 / vector ctor direction

`Stack<int> s({1,2,3})` 的 top 是 3——"end of items is the top"。实现即逐元素 push，语义自然成立；测试显式锁定这个方向（`top()==3`，pop 序 3,2,1）。
