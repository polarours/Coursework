# 06 · 踩坑清单 / Pitfalls

## 1. 忘记消费分号 / Forgetting to consume semicolons

- 症状 / Symptom：`未知语句 Token(;,';')`。
- 修复 / Fix：在 `block()` 里每条语句后 `if peek()==';': eat(';')`。

> **English:** Hand-written parsers must consume every token. A leftover terminator becomes a spurious "unknown statement" error.

## 2. token 类型不一致 / Inconsistent token types

- 症状 / Symptom：比较表达式无法解析。
- 原因 / Cause：词法器产生 `<` 类型，语法器期望 OP 类型。
- 修复 / Fix：统一约定——所有比较符（单/双字符）都是 OP。

## 3. `=` 与 `==` 混淆 / Confusing `=` and `==`

- 症状 / Symptom：赋值解析失败。
- 修复 / Fix：`==` 在双字符分支处理为 OP；单字符 `=` 作为赋值类型，放在普通字符分支。

## 4. 回填位置算错 / Wrong backpatch offset

- 症状 / Symptom：if/while 跳转跑到错误位置，死循环或跳过语句。
- 修复 / Fix：回填用生成完分支后的 `len(code)`，注意 else 存在时先记录 JMP 位置。

## 5. 栈不平衡 / Stack imbalance

- 症状 / Symptom：PRINT 弹出错误的值。
- 修复 / Fix：保持不变量——每个表达式生成的代码执行后栈净增 1；BINOP 弹 2 压 1。
