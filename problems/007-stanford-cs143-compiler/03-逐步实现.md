## 阶段 1 / Stage 1 — 词法分析

把字符流切成 Token；关键字单独分类，标识符为 ID，数字为 NUM，比较符统一为 OP。

Split characters into tokens; keywords, IDs, numbers, and operators each get a type.

```python
elif src[i:i+2] in ("<=", ">=", "==", "!="):
```

## 阶段 2 / Stage 2 — 语法分析

递归下降：block → stmt → expr → compare → add → mul → atom，优先级由调用层次体现。

Recursive descent; precedence is encoded in the call hierarchy.

```python
def add(self):
    node = self.mul()
    while self.peek().type in ("+", "-"):
        op = self.eat(self.peek().type).value
        node = Bin(op, node, self.mul())
    return node
```

验证 / Verify: AST 正确解析 `x*x + y*y` 为 `Bin('+', Bin('*', x, x), Bin('*', y, y))`。

## 阶段 3 / Stage 3 — 代码生成

AST → 栈指令；if/while 用占位跳转 + 回填。

AST → stack instructions; if/while use placeholder jumps + backpatching.
