# 07 · 延伸练习 / Follow-up exercises

## 练习 1 / Exercise 1 — 类型检查（中等）

在 AST 上做静态类型检查：区分整数与布尔；禁止 `3 < true` 这类非法比较；if/while 条件必须是布尔。用真实测试用例验证合法程序通过、非法程序报错。

提示 / Hint：给每个 AST 节点加 `infer_type()`；比较运算返回 bool，算术返回 int（或报错）。

> **English:** Add a static type checker over the AST that rejects invalid operations. This is CS143's semantic-analysis phase in miniature.

## 练习 2 / Exercise 2 — 函数与调用（困难）

扩展语言支持函数定义与调用（`fun f(x) { ... }`、`f(3)`），在虚拟机中加入 CALL/RET 指令与栈帧（frame pointer）。用递归计算斐波那契数验证。

提示 / Hint：栈帧保存返回地址、实参、局部变量；CALL 压新帧，RET 弹帧并跳回返回地址。

> **English:** Extend the language with functions and calls. Add CALL/RET instructions and stack frames to the VM; verify with recursive Fibonacci.

## 练习 3 / Exercise 3 — 生成 x86-64 汇编（综合）

把栈式指令翻译成 x86-64 汇编（用 `%rax`、`%rsp`，调用 `printf` 输出）；用 gcc 汇编链接并运行，对比与虚拟机执行的结果。

提示 / Hint：PUSH→`pushq`，BINOP(+)->`popq %rbx; popq %rax; addq %rbx,%rax; pushq %rax`；PRINT 调用 printf。

> **English:** Translate the stack VM instructions to x86-64 assembly, assemble with gcc, and compare the output with the VM run. This bridges the mini-compiler to a real backend.
