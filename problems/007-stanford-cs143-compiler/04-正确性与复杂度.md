# 04 · 正确性与复杂度 / Correctness and complexity

## 不变量 / Invariants

1. **token 完整性**：源码中每个非空白字符都被消费，无跳过。
   *Every non-whitespace character is consumed — none skipped.*
2. **AST 结构**：二元操作的左右子树非空；语句块保持源码顺序。
   *Binary nodes have both children; blocks preserve source order.*
3. **栈平衡**：每个表达式生成的代码执行后栈净增 1（一个结果值）。
   *Each expression leaves exactly one value on the stack.*
4. **跳转目标有效**：回填后的 JZ/JMP 目标都指向合法指令下标。
   *Backpatched jump targets are valid instruction indices.*

> **English:** The stack-balance invariant (3) is what makes composition work: `x*x + y*y` pushes x,x → BINOP(*) → x², pushes y,y → BINOP(*) → y², then BINOP(+) → sum. Each subexpression leaves one value.

## 证明思路 / Proof sketch

**为什么递归下降能正确表达优先级？/ Why does recursive descent encode precedence?**

`expr → compare → add → mul → atom` 的调用链中，越靠下的结合越紧：`mul` 在 `add` 内部调用，所以 `*` 先于 `+` 结合。这是文法 `E → E+T | T; T → T*F | F` 的直接实现。
The call chain `expr → compare → add → mul → atom` makes tighter-binding operators deeper in the chain — a direct encoding of the grammar.

**回填为什么正确？/ Why is backpatching correct?**

生成 if 的 then 分支前不知道结束位置，先放 `JZ(None)`；生成完 then（和 else）后，当前 `len(code)` 就是跳转目标。回填后 JZ 跳到条件为假时应执行的位置——即 then 块之后（或 else 块之后）。

## 复杂度 / Complexity

| 阶段 / Phase | 时间 / Time | 空间 / Space |
|---|---|---|
| 词法 / Lexing | O(n)（n 为源码长度）| O(n) token |
| 语法 / Parsing | O(n) | O(n) AST |
| 代码生成 / Codegen | O(AST 节点数) | O(指令数) |
| 执行 / Execution | O(指令数 × 循环次数) | O(栈深 + 变量数) |
