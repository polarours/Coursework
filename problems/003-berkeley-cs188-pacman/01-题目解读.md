## 需求概述 / Requirements

CS188 的 Pacman 项目用一个游戏场景串起人工智能的核心算法：让 Pacman 在迷宫里吃豆子、躲避幽灵。本项目覆盖四种代表性方法：

CS188's Pacman projects use one game to carry core AI algorithms: make Pacman eat all dots while avoiding ghosts. Our walkthrough covers four representative methods:

1. **A* 搜索 / A***：在网格中找到到目标的最短路径（Project 1）。
2. **Minimax + α-β 剪枝**：在 Pacman 与幽灵的对抗中选择最优行动（Project 2）。
   *Adversarial search with alpha-beta pruning.*
3. **MDP 值迭代 / Value iteration**：在随机转移模型下计算每个状态的最优价值（Project 3）。
4. **Q-learning**：无模型强化学习，通过与环境交互学出策略（Project 3/4）。
   *Model-free reinforcement learning from interaction.*

> **English:** The pedagogical strength of Pacman is that all four algorithms share the same concrete, visual domain. Students can *see* whether their agent is playing well, which makes abstract algorithm differences tangible.

## 输入与输出 / Input and output

- 输入：网格世界（墙、豆子、Pacman/幽灵位置）/ Input: grid world with walls, food, agent positions.
- 输出：行动序列或策略（如路径、动作值 Q(s,a)、状态值 V(s)）。
  *Output: action sequence or policy (path, Q-values, state values).*

## 边界条件 / Edge cases

- 墙阻隔导致没有通路 → A* 返回 None。*No path due to walls → A* returns None.*
- Minimax 搜索深度有限 → 用评估函数估计叶节点。
  *Finite search depth → evaluate leaf nodes with a heuristic.*
- Q-learning 的探索/利用权衡 → ε-greedy 防止陷入局部最优。
  *Exploration vs exploitation → ε-greedy avoids local optima.*
