# 02 · 设计思路 / Design rationale

## 整体架构 / Architecture

```text
              ┌──────────── GridWorld（共享环境）────────────┐
              │  walls / food / pacman / ghost              │
              └───────┬─────────┬─────────┬─────────┬────────┘
                      │         │         │         │
                   A*搜索   Minimax   值迭代    Q-learning
                   (路径)   (对抗)    (有模型)   (无模型)
```

四种算法共享同一个环境接口，但解决不同层次的问题：从「已知地图找路」到「对抗」，再到「有模型的规划」和「无模型的学习」。
All four algorithms share one environment interface but solve different problems: pathfinding, adversarial search, model-based planning, and model-free learning.

> **English:** This layering mirrors the AI curriculum: search → adversarial search → planning under uncertainty → learning from experience. Teaching them in one codebase makes the progression explicit.

## 关键决策 / Key decisions

| 决策 / Decision | 选择 / Choice | 理由 / Why |
|---|---|---|
| 环境表示 / Environment | 字符网格 + dataclass State | 轻量、可视化、便于打印真实轨迹 / lightweight, visible, easy to print real traces |
| A* 启发式 / Heuristic | 曼哈顿距离到最近豆子 | 可采纳（不高估），保证最优 / admissible, preserves optimality |
| 对抗搜索 / Adversarial | Minimax + α-β 剪枝 | 剪枝减少搜索节点；深度 4 便于演示 / pruning reduces nodes; depth 4 for demo |
| 规划 / Planning | 值迭代，γ=0.9 | 折扣因子体现未来奖励的不确定性 / discount captures uncertainty about the future |
| 学习 / Learning | 表格 Q-learning，ε=0.1，固定种子 42 | 结果可复现；能观察到步数下降 / reproducible; observable improvement |
| 状态去重 / State key | `(pacman, ghost, food)` 不含 steps | 搜索去重的标准做法 / standard for search deduplication |

## 备选方案 / Alternatives

- **用真实的 CS188 skeleton**：依赖官方包与 autograder，不适合自包含的学习库； ours is standalone.
- **用深度学习代替表格 Q-learning**：CS188 后期才涉及；表格版更能讲清 RL 基本概念。
  *Deep RL comes later in the curriculum; tabular Q-learning makes the concepts transparent.*
- **用 BFS 代替 A***：BFS 也能找最短路，但 A* 的启发式是核心教学点。
  *BFS also finds shortest paths, but the heuristic is the teaching point.*

> **English:** Fixing the random seed (42) is not cosmetic — without it, the Q-learning improvement claim would not be reproducible, which violates this project's evidence discipline.
