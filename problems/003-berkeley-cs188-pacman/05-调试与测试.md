## 输出解读 / Reading the output

- A* 路径绕开了第 1 行 (1,1)-(3,1) 的墙，先向下走到 y=4 再向右——最短路径。
  *The path detours around the wall on row 1 — still optimal.*
- 值迭代中 `V[goal]=10`（终点即时奖励），`V[(4,4)]=19`（下一步就到终点：10+0.9×10），数字自洽。
  *Values are self-consistent: goal=10, neighbor=10+0.9×10=19.*
- Q-learning 步数下降 25.6 → 9.6 是最有说服力的结果：策略确实在改进。
  *The drop from 25.6 to 9.6 steps is the most convincing evidence of learning.*
- 游戏轨迹显示 Pacman 用 13 步吃光 3 颗豆子，终局地图中豆子全部消失。

## 失败案例与排查 / Failures and debugging

| 症状 / Symptom | 原因 / Cause | 修复 / Fix |
|---|---|---|
| A* 返回 None | 目标被墙完全包围 / goal enclosed by walls | 检查世界连通性 / verify world connectivity |
| Minimax 在深度 0 仍返回任意值 | 缺少叶节点评估 / missing leaf evaluation | 加 `evaluate()`：近豆子、远幽灵加分 / added evaluation |
| 值迭代不收敛 | γ≥1 导致价值发散 / γ≥1 causes divergence | 取 γ=0.9 / use γ=0.9 |
| Q-learning 结果每次不同 | 随机种子不固定 / unseeded RNG | 固定 `random.Random(42)` / fixed seed |
| Pyright 报 `Import "pacman" could not be resolved` | 测试用 `sys.path.insert` 动态加载，静态分析器看不到 / static analyzer can't see runtime path insertion | 实际运行通过；属误报，不影响 / runtime works; false positive |

> **English:** All five tests passed. Value iteration's numbers are self-consistent (goal = 10, its neighbor = 10 + 0.9x10 = 19). The most convincing evidence is the Q-learning improvement from 25.6 to 9.6 steps, which shows the agent learning from interaction rather than merely running code.
