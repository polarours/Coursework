# 06 · 踩坑清单 / Pitfalls

## 1. 启发式函数高估 / Overestimating heuristic

- 症状 / Symptom：A* 找到的路径不是最短。
- 原因 / Cause：用了欧几里得距离或错误的下界。
- 修复 / Fix：网格四邻接用曼哈顿距离，保证可采纳。

> **English:** An inadmissible heuristic breaks A*'s optimality guarantee — the classic AI exam trap.

## 2. Minimax 忘记叶节点评估 / Missing leaf evaluation

- 症状 / Symptom：搜索到深度上限就返回 0，忽略局面好坏。
- 修复 / Fix：`evaluate()` 综合距离豆子（近了好）和距离幽灵（远了好）。

## 3. α-β 剪枝写反比较 / Wrong pruning comparison

- 症状 / Symptom：剪掉本应探索的分支，得到错误值。
- 修复 / Fix：max 节点用 `alpha >= beta` 剪枝，min 节点对称处理。

## 4. 值迭代的 γ 太大 / Discount too large

- 症状 / Symptom：价值不收敛或振荡。
- 修复 / Fix：γ=0.9，并设收敛阈值 θ=1e-6。

## 5. Q-learning 不探索 / No exploration

- 症状 / Symptom：策略卡在次优动作上。
- 修复 / Fix：ε-greedy（ε=0.1）；实测前 10 轮平均 25.6 步正是探索的代价。

## 6. 结果不可复现 / Non-reproducible results

- 症状 / Symptom：同样的代码每次运行步数不同。
- 修复 / Fix：固定随机种子 42。这是本项目"实测纪律"的硬性要求。
