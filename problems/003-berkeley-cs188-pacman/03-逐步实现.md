# 03 · 逐步实现 / Step-by-step implementation

## 阶段 1 / Stage 1 — 网格世界

用 `dataclass` 表示状态，数组表示墙，字典存 Q 值。字符网格便于打印真实轨迹。

A frozen dataclass for state; ASCII rendering for real, printable traces.

```python
@dataclass(frozen=True)
class State:
    pacman: tuple[int, int]
    ghost: tuple[int, int]
    food: tuple[tuple[int, int], ...]
    steps: int = 0
```

验证 / Verify: `grid.display(...)` 打印出 P、G、豆子的真实布局。

## 阶段 2 / Stage 2 — A* 搜索

优先队列按 `g + h` 排序，`h` 是到最近豆子的曼哈顿距离。

Priority queue ordered by `g + h`; `h` is Manhattan distance to the nearest dot.

```python
heapq.heappush(frontier, (ng + heuristic(nb), ng, nb))
```

验证 / Verify: 从 (0,0) 到 (5,4) 得到 10 步路径，绕开 (1,1)-(3,1) 的墙。

## 阶段 3 / Stage 3 — Minimax + α-β

Pacman 层取 max，Ghost 层取 min；当 `alpha >= beta` 时剪枝。深度 4。

Max at Pacman nodes, min at ghost nodes; prune when `alpha >= beta`. Depth 4.

```python
if alpha >= beta:
    break  # beta 剪枝
```

验证 / Verify: 深度 4 的 minimax 值 = −0.50，与静态评估一致（该局面下没有更好的走法）。

## 阶段 4 / Stage 4 — MDP 值迭代

反复更新 `V(s) = max_a [reward(s,a) + γ·V(s')]`，直到变化小于 θ。

Iteratively update state values until convergence.

```python
best = max(best, reward + gamma * V[nb])
```

验证 / Verify: 终点旁 (4,4) 的价值 19.000 远高于起点 (0,0) 的 8.179——符合直觉。

## 阶段 5 / Stage 5 — Q-learning

ε-greedy 选动作，更新 `Q(s,a) += α[r + γ·max Q(s',·) − Q(s,a)]`。

ε-greedy action selection with the standard temporal-difference update.

```python
Q[(s, a)] = q(s, a) + alpha * (reward + gamma * future - q(s, a))
```

验证 / Verify: 300 轮后平均步数从前 10 轮的 25.6 降到后 10 轮的 9.6——学习确实发生了。

> **English:** Five stages map the shared grid world to four AI methods. A* finds a 10-step path around the wall; minimax at depth 4 returns -0.50; value iteration gives V(4,4)=19.000 near the goal versus V(0,0)=8.179 at the start; Q-learning reduces average steps from 25.6 to 9.6 over 300 episodes; and a traced game eats all three dots in 13 moves.
