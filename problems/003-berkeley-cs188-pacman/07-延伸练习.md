# 07 · 延伸练习 / Follow-up exercises

## 练习 1 / Exercise 1 — 幽灵的对抗策略（中等）

当前 Minimax 中幽灵只是简单最小化评估函数。请为幽灵实现多种策略：追逐型（朝 Pacman 走）、逃跑型（远离 Pacman）、随机型。用 Minimax 对抗这些策略，观察 Pacman 胜率变化。

提示 / Hint：在 `evaluate` 中引入策略权重；或把幽灵策略作为搜索中的对手模型。

> **English:** Implement multiple ghost policies (chaser, fleeing, random) and measure Pacman's win rate against each. This teaches that adversarial search assumes a specific opponent model.

## 练习 2 / Exercise 2 — SARSA 与 Q-learning 对比（困难）

实现 SARSA（on-policy）并与 Q-learning（off-policy）对比：在含"陷阱"格的网格中，两者学到的策略有何不同？用真实数据说明。

提示 / Hint：SARSA 更新用实际采取的下一动作 a'，Q-learning 用 max Q(s',·)。陷阱附近二者差异最明显。

> **English:** Implement SARSA and compare it with Q-learning near a trap state. Explain the difference between on-policy and off-policy learning using your measured results.

## 练习 3 / Exercise 3 — 深度 Q 网络（综合）

把表格 Q-learning 换成神经网络近似（DQN），加入经验回放与目标网络；在更大的网格上训练，画出 reward 曲线。

提示 / Hint：可用 PyTorch；状态用网格的 one-hot 编码；经验回放打破样本相关性。

> **English:** Replace the Q-table with a neural network (DQN) with experience replay and a target network. Train on a larger grid and plot the reward curve.
