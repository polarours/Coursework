# 04 · 正确性与复杂度 / Correctness and complexity

## 不变量 / Invariants

1. **A* 最优性**：启发式可采纳（曼哈顿距离不高估实际步数）→ 找到的路径最短。
   *Admissible heuristic → A* returns an optimal path.*
2. **Minimax 正确性**：α-β 剪枝只跳过不影响最终值的分支。
   *Alpha-beta pruning skips only branches that cannot affect the result.*
3. **值迭代收敛**：γ<1 保证贝尔曼更新是压缩映射，迭代收敛到唯一最优值。
   *γ<1 makes the Bellman update a contraction; iteration converges.*
4. **Q-learning 收敛**：在充分探索（ε>0）与衰减学习率下收敛到最优 Q。
   *With sufficient exploration and decaying learning rate, Q-learning converges.*

> **English:** The admissible-heuristic argument and the contraction-mapping argument are the two theoretical pillars behind search and planning. Understanding *why* they hold is what separates this project from simply calling a library.

## 证明思路 / Proof sketch

**为什么曼哈顿距离可采纳？/ Why is Manhattan distance admissible?**

网格中每步只能上下左右移动一格，从位置 p 到目标 g 至少需要 |Δx|+|Δy| 步；曼哈顿距离正是这个下界，不高估。

Each move changes one coordinate by one, so at least |Δx|+|Δy| steps are needed — exactly the Manhattan distance. It never overestimates.

**Q-learning 步数下降说明什么？/ What does the drop in steps show?**

前 10 轮平均 25.6 步（大量随机探索），后 10 轮平均 9.6 步（策略已收敛到接近最优路径）。这是强化学习"从经验中改进"的直接证据。

Early episodes average 25.6 steps (random exploration); late episodes average 9.6 (policy near-optimal) — direct evidence of learning from experience.

## 复杂度 / Complexity

| 算法 / Algorithm | 时间 / Time | 空间 / Space |
|---|---|---|
| A* | O(b^d)（b 为分支因子，d 为解深度）/ O(b^d) | O(b^d) |
| Minimax + α-β | 最好 O(b^(d/2))，最坏 O(b^d) / best O(b^(d/2)) | O(d) |
| 值迭代 | O(|S|·|A|·迭代次数) / O(\|S\|\|A\|·iters) | O(|S|) |
| Q-learning | O(episodes·steps·|A|) | O(|S|·|A|) |
