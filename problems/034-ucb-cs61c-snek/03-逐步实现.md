## Task 2：释放 / Freeing

```c
for (unsigned int i = 0; i < game->num_rows; i++) free(game->board[i]);
free(game->board);
free(game->snakes);
free(game);
```

顺序无关（它们互不指向），但**每行都要单独 free**——`board` 是指针数组，只 free 它会泄漏所有行。

`free(NULL)` 是合法的，所以 `game == NULL` 的检查只是防御性写法。

## Task 3：打印 / Printing

```c
for (unsigned int i = 0; i < game->num_rows; i++) fprintf(fp, "%s", game->board[i]);
```

不补换行——行内已经有。这一点如果搞错，所有输出都会多一行空行，21 组测试同时失败。

## Task 4.1：七个 helper

字符到方向的两张映射表：

| 字符 | 行增量 | 列增量 |
|---|---|---|
| `^` `w` `W` | -1 | 0 |
| `v` `s` `S` | +1 | 0 |
| `<` `a` `A` | 0 | -1 |
| `>` `d` `D` | 0 | +1 |

实现成两个独立函数，各自处理行/列，用 `switch` 而不是查表——因为 `unsigned int` 的 `-1` 需要小心，`cur_row - 1` 在 `cur_row == 0` 时会下溢。棋盘有墙，实际不会发生，但这是值得知道的边界。

## Task 4.2–4.4：单步移动

```c
static char next_square(game_t *game, unsigned int snum) {
  snake_t *s = &game->snakes[snum];
  char head = get_board_at(game, s->head_row, s->head_col);
  return get_board_at(game, get_next_row(s->head_row, head),
                            get_next_col(s->head_col, head));
}
```

`update_head` 与 `update_tail` 都遵循“先改棋盘、后改结构体”的顺序：

```c
static void update_head(game_t *game, unsigned int snum) {
  snake_t *s = &game->snakes[snum];
  char head = get_board_at(game, s->head_row, s->head_col);
  unsigned int nr = get_next_row(s->head_row, head);
  unsigned int nc = get_next_col(s->head_col, head);

  set_board_at(game, s->head_row, s->head_col, head_to_body(head));  /* 旧头 → 身体 */
  set_board_at(game, nr, nc, head);                                  /* 新头 */
  s->head_row = nr; s->head_col = nc;
}
```

注意 `head` 是在改动棋盘**之前**读出来的——如果先写旧头再读，读到的是身体字符，方向就丢了。

## Task 4.5：推进

```c
void update_game(game_t *game, int (*add_food)(game_t *game)) {
  for (unsigned int i = 0; i < game->num_snakes; i++) {
    snake_t *s = &game->snakes[i];
    if (!s->live) continue;

    char next = next_square(game, i);
    if (next == '#' || is_snake(next)) {
      set_board_at(game, s->head_row, s->head_col, 'x');
      s->live = false;
      continue;
    }
    update_head(game, i);
    if (next == '*') add_food(game);
    else             update_tail(game, i);
  }
}
```

`add_food` 是函数指针，`main` 传入 `deterministic_food`。这样游戏逻辑不依赖具体的随机数实现，测试可以换成“固定角落放食物”（`corner_food` 就是这么写的）。

## Task 5：加载

```c
char *read_line(FILE *fp) {
  if (fp == NULL) return NULL;
  unsigned int cap = 32, len = 0;
  char *line = malloc(cap);
  line[0] = '\0';
  while (fgets(line + len, (int)(cap - len), fp) != NULL) {
    len += strlen(line + len);
    if (len > 0 && line[len-1] == '\n') return line;
    cap *= 2;
    line = realloc(line, cap);
  }
  if (len == 0) { free(line); return NULL; }
  return line;
}
```

`load_board` 用同样“容量翻倍”的思路管理行指针数组，行长不等长由 `read_line` 各自分配。

注意 `load_board` 结束时 `num_snakes = 0, snakes = NULL`——这是规格明确要求的，Task 6 才填。

## Task 6：初始化蛇

```c
static void find_head(game_t *game, unsigned int snum) {
  snake_t *s = &game->snakes[snum];
  unsigned int row = s->tail_row, col = s->tail_col;
  char c = get_board_at(game, row, col);
  while (!is_head(c)) {
    row = get_next_row(row, c);
    col = get_next_col(col, c);
    c = get_board_at(game, row, col);
  }
  s->head_row = row; s->head_col = col;
}
```

`initialize_snakes` 两遍扫描：第一遍数尾字符确定数组大小，第二遍填每个蛇的尾坐标并调用 `find_head`。

**为什么数尾而不是数头？** 因为死蛇的头是 `x`，不是 `WASD`；而尾字符 `wasd` 在所有蛇上都是一致的。用尾计数对活蛇死蛇都成立。

## Task 7：main

```c
if (in_filename) {
  FILE *fp = fopen(in_filename, "r");
  if (!fp) return -1;
  game = load_board(fp);
  fclose(fp);
  if (!game) return -1;
  game = initialize_snakes(game);
} else if (io_stdin) {
  game = load_board(stdin);
  if (!game) return -1;
  game = initialize_snakes(game);
} else {
  game = create_default_game();      /* 已经自带蛇，不再 initialize */
}

update_game(game, deterministic_food);
if (out_filename) save_board(game, out_filename);
else              print_board(game, stdout);
free_game(game);
```

默认分支**不调用** `initialize_snakes`：`create_default_game` 已经把蛇建好了，再调用一次会重新扫描并覆盖 `snakes` 指针，泄漏第一次分配的内存。
