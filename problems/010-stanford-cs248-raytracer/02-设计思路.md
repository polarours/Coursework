# 02 · 设计思路 / Design rationale

## 关键决策 / Key decisions

| 决策 / Decision | 选择 / Choice | 理由 / Why |
|---|---|---|
| 图像格式 | PPM（P3 文本）| 无需图像库，可直接查看 / no image lib needed |
| 相机 | 正交近似（方向由屏幕坐标决定）| 教学简化 / teaching simplification |
| 着色 | 环境光 + 漫反射 | Lambert 模型，直观 / Lambertian |
| 求交 | 解二次方程 | 解析解，精确 / analytic |

> **English:** The ray-sphere intersection is a quadratic: |o + td - c|² = r². The discriminant tells us if there's a hit; the smaller positive root is the nearest hit.
