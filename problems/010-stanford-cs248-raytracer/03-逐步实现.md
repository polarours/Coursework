# 03 · 逐步实现 / Step-by-step implementation

## 阶段 1 — Vec 与求交

```python
oc = origin - s.center
b = oc.dot(direction)
c = oc.dot(oc) - s.radius**2
disc = b*b - c
```

验证 / Verify: t=2.0，错开时 None。

## 阶段 2 — 着色

最近交点法线与光源方向点积 = 漫反射强度；加环境光 0.15。

## 阶段 3 — 渲染与 PPM

逐像素发射射线；输出 P3 格式（头 + RGB 三元组）。

验证 / Verify: 771 行；球心像素 (0.43,0,0) 比背景 (0.05,0.05,0.12) 更亮。
