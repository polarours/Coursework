# 01 · 题目解读 / Understanding the problem

## 需求概述 / Requirements

Stanford CS248 的图形学大作业包含光线追踪器。本项目实现核心：从相机发射射线，与场景球体求交，按光照着色，输出 PPM 图像。

Build a ray tracer: cast rays from the camera, intersect spheres, shade by lighting, output a PPM image.

> **English:** Ray tracing is a beautiful capstone: a few dozen lines of vector math produce a real image, making abstract geometry tangible.

## 验收 / Acceptance

- [x] 射线与球求交：t=2.0（球心 z=3，半径 1）
- [x] 射线错开球时无交点
- [x] 32×24 PPM：P3 头 + 771 行（3+768）
- [x] 球心像素比背景更亮
