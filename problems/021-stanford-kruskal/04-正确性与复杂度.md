# 04 · 正确性与复杂度 / Correctness and complexity

## 不变量 / Invariants

1. 并查集的每个集合对应一个连通分量。
2. MST 中任意两点间只有唯一路径（无环）。
3. 每步加入的边是当前不形成环的最小权重边（切割性质）。
   *Each step adds the smallest edge that doesn't form a cycle (cut property).*

> **English:** Correctness follows from the cut property: the minimum-weight edge crossing any cut belongs to some MST. Kruskal repeatedly picks such edges, so the result is minimum.

## 复杂度 / Complexity

| 操作 / Operation | 时间 / Time |
|---|---|
| find / union | O(α(n)) 均摊 / amortized |
| Kruskal 总计 | O(E log E)（排序主导）|

空间 O(n + E)。
