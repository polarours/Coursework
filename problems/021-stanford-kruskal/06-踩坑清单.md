# 06 · 踩坑清单 / Pitfalls

## 1. 忽略环检测 / Ignoring cycle detection

union 返回 False 表示两端已连通，必须跳过该边，否则 MST 会含环。
If union returns False, skip the edge — otherwise the MST contains a cycle.

## 2. 忘记路径压缩 / Missing path compression

不压缩会退化为 O(n) 查找，破坏并查集的复杂度优势。

## 3. 不连通图误判 / Misreading disconnected graphs

MST 边数少于 n-1 是正常结果（生成森林），不是错误。

> **English:** These pitfalls come from the algorithm's structure: cycle detection, path compression, and the interpretation of disconnected graphs.
