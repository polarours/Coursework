# 02 · 设计思路 / Design rationale

## 关键决策 / Key decisions

| 决策 / Decision | 选择 / Choice | 理由 / Why |
|---|---|---|
| 连通性 / Connectivity | 并查集 UnionFind | 近似 O(1) 的合并与查询 / near-constant ops |
| 优化 / Optimization | 路径压缩 + 按秩合并 | 均摊复杂度接近常数 / amortized near-constant |
| 边处理 / Edge processing | 按权重升序排序 | 贪心算法的核心 / core of the greedy approach |
| 环检测 / Cycle detection | union 返回 False 则跳过 | 保证生成树无环 / guarantees acyclicity |

> **English:** Kruskal is the textbook example of a greedy algorithm: sorting edges once and adding each edge if it connects two components. Union-find is the data structure that makes the "connects two components" test nearly free.
