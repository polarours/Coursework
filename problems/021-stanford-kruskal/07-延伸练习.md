# 07 · 延伸练习 / Follow-up exercises

## 练习 1 / Exercise 1 — Prim 算法（中等）

实现 Prim 算法（基于优先队列），与 Kruskal 在同一张图上对比 MST 总权重。

> **English:** Implement Prim's algorithm with a priority queue and compare the MST weight with Kruskal's.

## 练习 2 / Exercise 2 — 最小生成森林（困难）

处理不连通图，返回每个连通分量各自的 MST（生成森林）。

> **English:** Return a minimum spanning forest for disconnected graphs.

## 练习 3 / Exercise 3 — 次小生成树（综合）

求严格次小生成树的权重，用多张真实图验证结果。

> **English:** Find the weight of the strictly second-best spanning tree on several real graphs.
