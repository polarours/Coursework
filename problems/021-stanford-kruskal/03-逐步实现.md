# 03 · 逐步实现 / Step-by-step implementation

## 阶段 1 — UnionFind

`find` 中做路径压缩；`union` 按秩合并并维护 `components` 计数。

```python
def find(self, x):
    while self.parent[x] != x:
        self.parent[x] = self.parent[self.parent[x]]  # 路径压缩
        x = self.parent[x]
    return x
```

验证 / Verify: 合并 0-1、1-2 后 components 从 5 降到 3。

## 阶段 2 — Kruskal

按权重排序，逐边 union；成功则加入 MST 并累加权重；边数达到 n-1 时提前结束。

```python
for u, v, w in sorted(edges, key=lambda e: e[2]):
    if uf.union(u, v):
        mst.append((u, v, w)); total += w
```

验证 / Verify: 经典 9 点图 MST 总权重 37（与教科书答案一致）；不连通图只得到 2 条边。

> **English:** Each stage leaves a verifiable artifact: union-find component counts, then the MST weight on a graph with a known answer.
