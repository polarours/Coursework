# 07 · 延伸练习 / Follow-up exercises

## 练习 1 / Exercise 1 — 拥塞控制（中等）

在 TCPSender 中加入拥塞窗口 `cwnd`：慢启动（每收到一个 ACK，cwnd 加倍）与拥塞避免（线性增长）。实际发送窗口取 `min(rwnd, cwnd)`。用虚拟时钟模拟丢包，观察 cwnd 变化曲线。

提示 / Hint：区分接收窗口（rwnd）和拥塞窗口（cwnd）；超时后 cwnd 应重置为 1 并把 ssthresh 设为当前 cwnd 的一半。

> **English:** Add congestion control with slow start and congestion avoidance. The effective window is `min(rwnd, cwnd)`. Plot cwnd over time under simulated loss.

## 练习 2 / Exercise 2 — 快速重传（困难）

实现收到 3 个重复 ACK 时的快速重传：不等 RTO 到期就重发丢失段，并把 cwnd 减半（快速恢复）。

提示 / Hint：在 `receive_ack` 中统计连续相同 ACK 的次数；达到 3 时触发重传并进入快速恢复状态。

> **English:** Implement fast retransmit on three duplicate ACKs. Compare recovery time against RTO-based retransmission in your virtual clock.

## 练习 3 / Exercise 3 — 真实 Socket 集成（综合）

把教学版的 ByteStream 接到 Python 的 `socket` 上，实现真正的客户端/服务端数据传传输；用 `tcpdump` 或 Wireshark 抓包，对比你实现的段结构与真实 TCP 的异同。

提示 / Hint：注意本机回环抓包需要 root 权限；也可以用 `scapy` 构造/解析报文。

> **English:** Connect the teaching ByteStream to real Python sockets, capture traffic, and compare your segment logic with a production TCP stack.
