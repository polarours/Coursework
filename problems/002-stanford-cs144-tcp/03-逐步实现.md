# 03 · 逐步实现 / Step-by-step implementation

## 阶段 1 / Stage 1 — ByteStream

带容量的缓冲区，`push` 返回实际接收字节数（可能小于写入量，因为容量有限）。

A capacity-limited buffer; `push` returns the number of bytes actually accepted.

```python
def push(self, data: bytes) -> int:
    room = self.capacity - len(self._buf)
    take = data[:room]
    self._buf.extend(take)
    return len(take)
```

验证 / Verify: 容量 64 能装下测试数据 / capacity 64 holds our test data.

## 阶段 2 / Stage 2 — Reassembler

核心是「只接收 `index >= first_unassembled` 的字节」，然后不断从字典中取出连续字节。

Accept only bytes at `index >= first_unassembled`, then drain contiguous bytes from the dict.

```python
while self._first in self._pending:
    b = self._pending.pop(self._first)
    self._output.push(bytes([b]))
    self._first += 1
```

验证 / Verify: `test_reassembler` 中乱序插入 `def`、`abc`、重叠 `cde` 后得到 `abcdefg`。
Out-of-order and overlapping inserts converge to `abcdefg`.

## 阶段 3 / Stage 3 — 32 位序列号与接收端

```python
def wrap_add(x, n): return (x + n) % (1 << 32)
def wrap_sub(a, b): return (a - b) % (1 << 32)  # 从 b 到 a 的距离
```

SYN 建立基准：数据从 absolute index 0 开始。ackno = ISN + 1 + first_unassembled。

SYN establishes the baseline: data starts at absolute index 0; ackno = ISN + 1 + first_unassembled.

验证 / Verify: `test_wraparound` 中 ISN = 2^32−5，加 10 得 5；`test_receiver` 中乱序数据重组后 ackno = 1011。

## 阶段 4 / Stage 4 — 发送端重传

用虚拟时钟推进；超时则重发最早的未确认段，并把 RTO 翻倍。

Advance a virtual clock; on timeout, retransmit the earliest outstanding segment and double RTO.

```python
while self.timer_running and self.now - self.timer_start >= self.rto:
    self.timer_start = self.now
    self.rto *= 2
    self.retransmission_events.append(self.outstanding[0])
```

验证 / Verify: `test_sender_retransmission` 观测到 RTO 从 10 → 20 → 40。

## 阶段 5 / Stage 5 — 窗口与端到端

`send_segments` 只在 `bytes_in_flight < window` 时发送；ACK 到达后从 outstanding 移除已确认段。

`send_segments` only sends while `bytes_in_flight < window`; ACKs remove confirmed segments.

验证 / Verify: `test_end_to_end` 中 4 个段把 `the quick brown fox` 完整送达，eof=True。

> **English:** The implementation is built in five stages — ByteStream, Reassembler, 32-bit wrapping sequence numbers with TCPReceiver, sender retransmission with a virtual clock, and sliding window with ACKs. Each stage has a verifiable artifact: reassembly converges to `abcdefg`, ISN 2^32-5 plus 10 wraps to 5, RTO backs off 10→20→40, and an end-to-end run delivers the 19-byte stream in four segments.
