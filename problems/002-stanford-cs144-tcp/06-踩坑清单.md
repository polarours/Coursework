# 06 · 踩坑清单 / Pitfalls

## 1. 忘记 SYN/FIN 占序列号 / Forgetting SYN/FIN consume seqnos

- 症状 / Symptom：ackno 总是差 1；窗口计算溢出。
- 原因 / Cause：只把 payload 长度计入序列号消耗。
- 修复 / Fix：统一用 `Segment.length()` = payload + syn + fin。
- 实测 / Evidence：`final flight` 中 FIN 的 seqno=11 而 payload 为空。

> **English:** This is the #1 off-by-one source in TCP labs. Centralize the rule in one method so every caller gets it right.

## 2. 32 位回绕用普通比较 / Using plain comparison on wrapping seqnos

- 症状 / Symptom：接近 2^32 时 ACK 判断完全错误。
- 修复 / Fix：所有序列号比较用 `wrap_sub(a, b)` 得到「从 b 到 a 的距离」，再判断正负与范围。

## 3. 重叠数据被重复计数 / Overlapping data counted twice

- 症状 / Symptom：重组结果出现重复字节。
- 修复 / Fix：`index < first_unassembled` 的字节直接忽略并计数；实测 `duplicate_bytes=3`。

## 4. 零窗口死锁 / Zero-window deadlock

- 症状 / Symptom：接收窗口为 0 时发送端停止一切发送，永远等不到窗口更新。
- 修复 / Fix：`window = max(window, 1)`，持续发探测段。

## 5. 用真实 sleep 做重传测试 / Using real sleeps for retransmission tests

- 症状 / Symptom：测试慢、偶发失败、CI 上更糟。
- 修复 / Fix：虚拟时钟 `tick(ms)`——本实现中 `tick(10)`、`tick(9)`、`tick(11)` 精确控制边界。

## 6. 测试自身写错 / The test itself is wrong

- 症状 / Symptom：开发中有 3 次断言失败其实是测试期望算错，而非实现错误。
- 教训 / Lesson：先手工推算再断言；实测输出是唯一裁判。详见 05 的失败案例表。
