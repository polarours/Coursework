# 04 · 正确性与复杂度 / Correctness and complexity

## 不变量 / Invariants

1. **重组单调性 / Monotonicity**：`first_unassembled` 只增不减。
   *`first_unassembled` never decreases.*
2. **ackno 正确性**：ackno = ISN + 1 + 连续已接收字节数（模 2^32）。
   *ackno = ISN + 1 + contiguous bytes received (mod 2^32).*
3. **窗口不超限**：`bytes_in_flight ≤ window`（SYN/FIN 也计入）。
   *`bytes_in_flight ≤ window`, counting SYN/FIN.*
4. **ACK 单调**：只接受向前推进且不超过 `next_seq` 的 ACK。
   *Only ACKs that advance but don't exceed `next_seq` are accepted.*

> **English:** Invariant 3 is where most students fail: they count only payload bytes and forget that SYN and FIN each occupy one sequence number. Our `Segment.length()` centralizes that rule.

## 证明思路 / Proof sketch

**为什么 ackno 加 1？/ Why +1 in ackno?**

SYN 消耗一个序列号（ISN），所以第一个数据字节的序列号是 ISN+1。若已连续收到 k 字节数据，下一个期望序列号就是 ISN+1+k。

SYN consumes ISN, so the first data byte is at ISN+1. After k contiguous bytes, the next expected seqno is ISN+1+k.

**乱序重组的正确性 / Correctness of reassembly**

只在 `first_unassembled` 存在时才推进，保证输出到字节流的字节永远连续、无重复。重复字节（index < first_unassembled）被计入 `duplicate_bytes` 并忽略——实测中该值为 3。

Draining only from `first_unassembled` guarantees contiguous, duplicate-free output. Duplicates (index < first_unassembled) are counted and ignored — measured value: 3.

|---|---|---|
| 插入子串 / Insert substring | O(k)（k 为子串长度）/ O(k) | O(u)（u 为乱序字节数）/ O(u) |
