# 02 · 设计思路 / Design rationale

## 关键决策 / Key decisions

| 决策 / Decision | 选择 / Choice | 理由 / Why |
|---|---|---|
| 词法 | 括号加空格后 split | 极简，足够教学 / minimal |
| 环境 | Env(parent) 链式查找 | 词法作用域的标准实现 / lexical scoping |
| 过程 | Procedure(params, body, env) | 闭包 = 代码 + 定义环境 / closure |
| 内置过程 | "#builtin:name" 字符串标记 | 与用户过程统一走 apply / uniform apply |

> **English:** The environment chain is what makes closures work: a lambda captures its defining environment, so `make-adder` can return a function that still knows `x`.
