# 04 · 正确性与复杂度 / Correctness and complexity

## 不变量 / Invariants

1. 变量 lookup 沿环境链向上，直到全局。
2. lambda 捕获定义时的环境（词法作用域）。
3. special form 的参数不求值（除非明确 evaluate）。

> **English:** Point 3 is the classic beginner trap: in `(if (< 1 2) 100 200)`, only one branch is evaluated — if you evaluate all arguments first, the interpreter is wrong.

## 复杂度 / Complexity

每次求值 O(表达式节点数 + 环境深度)。
