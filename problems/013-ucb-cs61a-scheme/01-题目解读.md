# 01 · 题目解读 / Understanding the problem

## 需求概述 / Requirements

CS61A 的 Scheme 解释器项目是 SICP 风格的经典作业。本项目实现一个支持核心 special form 的解释器：
CS61A's Scheme interpreter is a classic SICP-style project. We support:

- quote、define、lambda、if、begin
- 算术与比较：+ - * = < >
- 列表原语：car、cdr、cons、list、null?

> **English:** Writing an interpreter is the best way to truly understand evaluation, environments, and closures — the conceptual core of programming languages.

## 验收 / Acceptance

- [x] 算术与 if、list 原语正确
- [x] 递归阶乘 5! = 120
- [x] 闭包：make-adder 返回的函数记住 x
