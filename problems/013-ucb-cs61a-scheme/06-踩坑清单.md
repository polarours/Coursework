# 06 · 踩坑清单 / Pitfalls

## 1. special form 参数求值 / Evaluating special-form args

if/lambda/quote 的参数不能提前全部求值，否则语义错误。

## 2. 环境链方向 / Environment chain direction

lookup 必须向 parent 查找；define 只在当前环境定义。

## 3. 闭包捕获时机 / Closure capture time

lambda 捕获的是定义时的 env 对象，不是调用时的。

> **English:** Three pitfalls: special-form arguments must not be eagerly evaluated (if evaluates only one branch); lookup walks toward the parent while define stays in the current environment; and a lambda captures the environment object at definition time, not at call time.
