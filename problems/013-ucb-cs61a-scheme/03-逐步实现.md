# 03 · 逐步实现 / Step-by-step implementation

## 阶段 1 — 词法与语法

tokenize 用空格包裹括号；parse 递归构造嵌套列表；' 展开为 (quote ...)。

## 阶段 2 — 求值

```python
if name == "lambda":
    return Procedure(list(expr[1]), expr[2], env)
```

special form 不求值参数；普通应用先求过程再求参数。

## 阶段 3 — 闭包验证

```scheme
(define make-adder (lambda (x) (lambda (y) (+ x y))))
(define add5 (make-adder 5))
(add5 3)  ; => 8
```

验证 / Verify: 阶乘 120；闭包 8。

> **English:** Three stages: tokenize by padding parentheses with spaces and parse into nested lists; evaluate with special forms (quote/lambda/if handled before generic application); and verify closures. The factorial test returns 120 via recursion, and make-adder produces add5(3)=8, proving a lambda captures its defining environment.
