# 03 · 逐步实现 / Implementation

## 第一步：普通文本与注释 / Normal text and comments

先只处理这两种状态，跑通最基本的用例：

```c
case ST_NORMAL:
    if (c == '/') return ST_SLASH;
    putchar(c);
    return ST_NORMAL;

case ST_COMMENT:
    if (c == '*') return ST_COMMENT_STAR;
    if (c == '\n') putchar('\n');
    return ST_COMMENT;

case ST_COMMENT_STAR:
    if (c == '/') return ST_NORMAL;
    if (c == '*') return ST_COMMENT_STAR;
    if (c == '\n') putchar('\n');
    return ST_COMMENT;
```

`ST_COMMENT_STAR` 必须能“原地停留”：`/* a ***/` 里连续三个星号，前两个不构成结束符。只有 `*` 后面紧跟 `/` 才关闭注释。

## 第二步：字符串与字符字面量 / Literals

字面量的规则是“原样输出，直到遇到未转义的结束引号”：

```c
case ST_STRING:
    putchar(c);
    if (c == '\\') return ST_STRING_ESC;
    if (c == '"') return ST_NORMAL;
    return ST_STRING;

case ST_STRING_ESC:
    putchar(c);            /* 被转义的字符没有特殊含义 */
    return ST_STRING;
```

关键点：**转义状态下不检查引号**。`"a\"b"` 里第一个 `"` 后面是 `\`，进入 `ST_STRING_ESC`；下一个字符是 `"`，在转义状态里它只是普通字符，输出后回到 `ST_STRING`。字符串真正的结束是第二个未转义的 `"`。

字符字面量同理，只是引号字符不同。分成两套状态而不是用“当前引号类型”变量，是为了让 `consume` 保持无分支参数——状态本身已经编码了引号类型。

## 第三步：斜杠与重处理 / The slash and reprocessing

主循环里的特判：

```c
if (ctx.state == ST_SLASH) {
    if (c == '*') {
        ctx.comment_line = ctx.line;
        putchar(' ');
        ctx.state = ST_COMMENT;
    } else {
        putchar('/');
        ctx.state = ST_NORMAL;
        again = 1;              /* 这个字符还没被处理 */
    }
    continue;
}
```

`again = 1` 让 `do-while` 再转一圈，此时 `fresh` 已经是 0，所以换行不会被重复计数。

这条路径覆盖了 `a/b` 这种普通除法：`/` 进入 `ST_SLASH`，下一个字符 `b` 不是 `*`，输出 `/`，然后 `b` 以 `ST_NORMAL` 重新处理并输出。

## 第四步：EOF 与错误 / End of file

```c
if (ctx.state == ST_SLASH) {
    putchar('/');               /* 文件以孤立斜杠结尾 */
}

if (ctx.state == ST_COMMENT || ctx.state == ST_COMMENT_STAR) {
    fprintf(stderr, "Error: line %d: unterminated comment\n", ctx.comment_line);
    return EXIT_FAILURE;
}
```

两个 EOF 分支都不能省：

- `ST_SLASH`：`abc/` 这样的输入，斜杠还没输出就结束了。**这是本项目实际踩到的 bug**（见 05 章）。
- `ST_COMMENT`/`ST_COMMENT_STAR`：注释未闭合，报起始行号。

其他状态（字符串、字符、转义）在 EOF 时不需要特殊处理——它们的字符都已经原样输出了，题面明确说未终止的字面量不算错误。

## 完整状态转移表 / Transition table

| 状态 | 输入 | 输出 | 下一状态 |
|---|---|---|---|
| NORMAL | `/` | — | SLASH |
| NORMAL | `"` | `"` | STRING |
| NORMAL | `'` | `'` | CHARLIT |
| NORMAL | 其他 | 原字符 | NORMAL |
| SLASH | `*` | 空格 | COMMENT |
| SLASH | 其他 | `/` | NORMAL（重处理该字符） |
| COMMENT | `*` | — | COMMENT_STAR |
| COMMENT | 换行 | 换行 | COMMENT |
| COMMENT | 其他 | — | COMMENT |
| COMMENT_STAR | `/` | — | NORMAL |
| COMMENT_STAR | `*` | — | COMMENT_STAR |
| COMMENT_STAR | 换行 | 换行 | COMMENT |
| COMMENT_STAR | 其他 | — | COMMENT |
| STRING | `\` | `\` | STRING_ESC |
| STRING | `"` | `"` | NORMAL |
| STRING | 其他 | 原字符 | STRING |
| STRING_ESC | 任意 | 原字符 | STRING |
| CHARLIT | `\` | `\` | CHARLIT_ESC |
| CHARLIT | `'` | `'` | NORMAL |
| CHARLIT | 其他 | 原字符 | CHARLIT |
| CHARLIT_ESC | 任意 | 原字符 | CHARLIT |

这张表可以直接翻译成 `consume` 的 `switch`——实现和设计文档保持一一对应，是这类状态机最省心的写法。

## 编译 / Build

```bash
cc -std=c99 -Wall -Wextra -pedantic -O2 -o decomment decomment.c
```

`-Wextra` 会指出 `switch` 缺少分支的问题；本实现给 `ST_SLASH` 留了 `break`，因为它在主循环里处理。
