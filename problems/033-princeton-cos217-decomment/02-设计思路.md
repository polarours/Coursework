# 02 · 设计思路 / Design

## 状态集从哪里来 / Where the states come from

把“程序需要记住什么”列出来，状态数就确定了：

- 我现在在普通文本里吗？
- 我在字符串里吗？在字符字面量里吗？
- 我刚读完反斜杠，下一个字符被转义了吗？
- 我在注释里吗？我刚读完一个星号（可能是结束符的前半）吗？
- 我刚读完斜杠，下一个字符决定它是不是注释开始吗？

最后一条是唯一**需要向前看**的情况。除此之外每个字符都能独立决定输出与转移。

```c
enum State {
    ST_NORMAL, ST_SLASH,
    ST_STRING, ST_STRING_ESC,
    ST_CHARLIT, ST_CHARLIT_ESC,
    ST_COMMENT, ST_COMMENT_STAR
};
```

> **English:** Eight states, seven of which are decided by the current character alone. Only the slash needs one character of lookahead, and that is what forces the loop to be able to reprocess a character.

## 为什么斜杠要单独成状态 / Why the slash needs its own state

两种写法都能处理 `/*`：

**写法 A：读到 `/` 就预读下一个字符。**
问题在于预读会“吃掉”一个字符。如果它不是 `*`，你要么把它存起来等下一轮（引入一个单字符缓冲，等价于多一个状态），要么立刻处理它（打乱主循环的单字符节奏）。

**写法 B：读到 `/` 进入 `ST_SLASH`，下一轮再决定。**
主循环读到一个字符时，如果状态是 `ST_SLASH`：

- 是 `*` → 注释开始，输出一个空格，进入 `ST_COMMENT`
- 否则 → 输出 `/`，状态回 `ST_NORMAL`，然后**用同一个字符再走一遍**

写法 B 没有缓冲，代价是主循环要支持“重处理当前字符”。这就是代码里 `do { ... } while (again)` 的来源。

```c
if (ctx.state == ST_SLASH) {
    if (c == '*') {
        ctx.comment_line = ctx.line;
        putchar(' ');
        ctx.state = ST_COMMENT;
    } else {
        putchar('/');
        ctx.state = ST_NORMAL;
        again = 1;
    }
    continue;
}
```

## 输出的时机 / When to emit

规则只有三条，但它们决定了实现的形状：

| 事件 | 输出 |
|---|---|
| 进入注释 | 一个空格（立刻，不等注释结束） |
| 注释内遇到换行 | 一个换行 |
| 注释外遇到任何字符 | 该字符本身 |

“进入注释立刻输出空格”这个选择让实现变成纯流式：不需要记住注释内容，也不需要回填。

> **English:** Emitting the space at the opening rather than the closing `*/` keeps the filter single-pass and constant-memory — there is never a moment when the program holds text it has not yet written.

## 无全局变量 / Avoiding globals

题目把“不用全局变量”列为挑战部分。程序需要跨字符保存三样东西：状态、当前行号、注释起始行号。

用一个结构体承载它们，以指针传入处理函数：

```c
struct Ctx {
    enum State state;
    int line;
    int comment_line;
};

static enum State consume(struct Ctx *ctx, int c);
```

这满足“所有值都通过参数和返回值传递”的要求：结构体是指针参数，下一个状态是返回值。类型定义（`enum`、`struct`）在文件作用域是允许的——题目明确说“定义数据类型没问题，定义变量不行”。

## 主循环的形状 / The shape of the loop

```c
while ((c = getchar()) != EOF) {
    fresh = 1;
    do {
        again = 0;
        if (fresh && c == '\n') ctx.line++;
        fresh = 0;
        /* ST_SLASH 特判，或交给 consume */
    } while (again);
}
```

`fresh` 保证行号只在**第一次**看到换行时递增；重处理同一个字符时不会重复计数。这个细节在写的时候很容易漏，漏了之后“未终止注释报第几行”就会错位。
