# 04 · 正确性与复杂度 / Correctness and complexity

## 不变量 / The invariant

在任意时刻，程序内部状态满足：

> **I1.** 已经写出的输出，等于“输入前缀去注释后应有的结果”，且末尾没有悬而未决的字符。
> **I2.** `ctx.line` 等于已读入的换行数加一。
> **I3.** 若 `ctx.state` 是 `ST_COMMENT` 或 `ST_COMMENT_STAR`，`ctx.comment_line` 是当前注释的起始行。

三条一起，才能保证 EOF 时的错误消息行号正确——这也是题目把“不用全局变量”设成挑战部分的原因：行号必须在整个生命周期里跟着状态走。

> **English:** The invariant ties output, line counter and comment origin together; drop any one and the error message points at the wrong line.

## 归纳论证 / Inductive argument

对输入长度 n 归纳。

**基础（n = 0）**：无输入，无输出，状态 `ST_NORMAL`，退出码 `EXIT_SUCCESS`。符合规格对空文件的要求。

**归纳步**：设处理完前 k 个字符后 I1–I3 成立，考察第 k+1 个字符 c。

- 若状态是 `ST_NORMAL` 且 c 不是 `/`/`"`/`'`：输出 c，状态不变。输出仍然是“去注释后的前缀”，I2 在 c 是换行时加一，I3 不受影响。
- 若 c 是 `/`：不输出，进入 `ST_SLASH`。此时输出没变，但有一个字符被“记住”了——这是 I1 里“末尾没有悬而未决字符”的唯一例外，需要主循环在下一次迭代解决。若下一字符不是 `*`，斜杠被输出、字符被重处理，例外消除；若是 `*`，注释开始，输出空格，符合“注释替换为一个空格”。
- 若状态是 `ST_COMMENT`：除换行外不输出，I2 在换行时加一。注释内的换行被补回，行号得以保持。
- 若状态是 `ST_COMMENT_STAR` 且 c 是 `/`：注释结束，不输出。此时输出恰好是“注释替换为一个空格”，与单行注释规格一致。

关键在于 `ST_SLASH` 的引入把“向前看一个字符”变成了一个**可观察的状态**，从而让归纳假设可以精确陈述。

## 为什么空格必须补 / Why the space is mandatory

`int/**/x;` 与 `int x;` 等价，而 `intx;` 是另一个程序。C 标准把注释定义为“被一个空格替换”，不是“被删除”。测试用例 `a/*x*//*y*/b` → `a  b`（两个空格）验证了这条：每个注释各自贡献一个空格，不合并。

## 复杂度 / Complexity

| 指标 | 值 | 理由 |
|---|---|---|
| 时间 | O(n) | 每个字符最多被 `consume` 处理两次（`ST_SLASH` 重处理），常数因子 ≤ 2 |
| 空间 | O(1) | 只有三个整型/枚举字段，无缓冲、无递归 |
| I/O | 逐字符 | `getchar`/`putchar` 可能较慢；标准库通常有缓冲，实测 74 个文件在毫秒级完成 |

注意“每个字符最多处理两次”这个界：`ST_SLASH` 只可能由单个 `/` 进入，重处理时状态已经是 `ST_NORMAL` 且字符不是 `/`（若是 `/` 会再次进入 `ST_SLASH`——但这仍然有界，因为每个字符至多触发一次重处理）。因此最坏情况是 2n 次状态转移。

## 边界清单与对应测试 / Boundaries and their tests

| 边界 | 期望 | 对应测试 |
|---|---|---|
| 空输入 | 无输出，退出 0 | `empty input yields empty output` |
| 仅一个注释 | 一个空格 | `empty comment becomes a single space` |
| 文件以注释开头 | 空格 + 正文 | `comment at start of file` |
| 相邻两个注释 | 两个空格 | `two adjacent comments give two spaces` |
| 文件以孤立 `/` 结尾 | 输出 `/` | `trailing slash at end of file is emitted` |
| 文件以 `/*` 结尾 | 空格 + 错误 | `file ending in an opener is unterminated` |
| 注释跨 3 行 | 空格 + 2 个换行 | `multi-line comment keeps every newline` |
| 注释内含引号 | 正常关闭 | `comment containing quotes still closes` |
| 字符串内注释标记 | 原样 | `comment markers inside a string are literal` |
| 转义引号 | 不结束字符串 | `escaped quote does not end the string` |
| 未终止字符串 | 原样，不报错 | `unterminated string swallows the comment` |
| 未终止注释 | 报起始行，退出 1 | `unterminated comment reports its first line` |

这张表就是 05 章测试套件的骨架：每条边界至少一个用例，规格给出的例子全部收录。
