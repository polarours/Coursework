# 02 · 设计思路 / Design rationale

## 关键决策 / Key decisions

| 决策 / Decision | 选择 / Choice | 理由 / Why |
|---|---|---|
| 状态表示 | 9 元元组 | 可哈希，适合做 visited key / hashable |
| 启发式 | 曼哈顿距离 | 可采纳且一致 / admissible & consistent |
| 优先队列 | heapq + f 值 | A* 标准做法 / standard |
| 可解性 | 逆序数奇偶 | O(n²) 精确判定 / exact test |

> **English:** Manhattan distance is consistent for the 8-puzzle: moving one tile changes h by at most 1, which equals the step cost. Consistency implies A* never needs to revisit a closed node.
