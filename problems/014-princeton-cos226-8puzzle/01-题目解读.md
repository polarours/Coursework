# 01 · 题目解读 / Understanding the problem

## 需求概述 / Requirements

Princeton COS 226 的 8-puzzle 是经典的 A* 搜索作业：3×3 滑块拼图，用最少步数复原。
The 8-puzzle is a classic A* assignment: solve a 3×3 sliding puzzle in minimum moves.

1. **曼哈顿距离启发式**：所有方块到目标位置的距离和，是可采纳启发式。
2. **A* 搜索**：按 f = g + h 扩展节点，保证最优解。
3. **可解性判定**：逆序数奇偶性。

> **English:** The 8-puzzle teaches heuristic search beautifully: an admissible heuristic (Manhattan distance) guarantees A* finds the optimal solution.

## 验收 / Acceptance

- [x] 1 步局面解长度 1
- [x] 打乱局面 A* 找到解（h=4，4 步）
- [x] 不可解局面正确判定并返回 None
- [x] A* 最优性验证
