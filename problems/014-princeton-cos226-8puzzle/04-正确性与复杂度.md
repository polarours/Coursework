# 04 · 正确性与复杂度 / Correctness and complexity

## 不变量 / Invariants

2. 每个状态只保留最小 g（best_g）。
3. 可解性判定正确：不可解状态返回 None。

> **English:** The unsolvable test case `(1,2,3,4,5,6,8,7,0)` has an odd inversion count — a classic example. Our solver correctly returns None.
