# 06 · 踩坑清单 / Pitfalls

## 1. 不可解局面 / Unsolvable states

A* 对不可解局面会搜完整个状态空间。先做逆序数判定，直接返回 None。

## 2. 启发式必须可采纳 / Admissible heuristic

用错了（如高估）的启发式会丢失最优性。曼哈顿距离是安全的。

## 3. closed set 的 g 值更新 / Reopening nodes

若发现更短路径到达已访问状态，必须更新并重新入队（best_g 处理）。

> **English:** Three pitfalls: A* would exhaust the whole state space on an unsolvable state, so check the inversion parity first; the heuristic must stay admissible or optimality is lost; and if a shorter path to an already-visited state is found, best_g must be updated and the node re-queued.
