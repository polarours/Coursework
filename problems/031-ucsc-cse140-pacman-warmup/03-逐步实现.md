# 03 · 逐步实现 / Step-by-step implementation

## buyLotsOfFruit

```python
def buyLotsOfFruit(orderList):
    totalCost = 0.0
    for fruit, pounds in orderList:
        if fruit not in FRUIT_PRICES:
            return None          # 缺货：None 表示无效订单
        totalCost += FRUIT_PRICES[fruit] * pounds
    return totalCost
```

顺序扫描而非 `sum(...)` 一行式的理由：中途发现缺货必须**立即**返回 None，生成器式写法做不到提前退出（除非用 try/except，牺牲可读性）。

## shopSmart

```python
def shopSmart(orderList, fruitShops):
    bestShop, bestPrice = None, None
    for fruitShop in fruitShops:
        price = fruitShop.getPriceOfOrder(orderList)
        if price is not None and (bestPrice is None or price < bestPrice):
            bestShop, bestPrice = fruitShop, price
    return bestShop
```

两个 None 各司其职：`bestPrice is None` 处理"第一个可供货商店"的初始化，`price is not None` 处理供货失败。
