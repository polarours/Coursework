# 07 · 延伸练习 / Extensions

## 1. p1：真正的搜索大作业 / p1: the real search project

upstream p1（`edulinq/pacai v2.1.0`，已验证可克隆）要求实现 `singlesearch.py` 的 8 个函数：DFS、BFS、UCS、A*、CornersProblem、FoodSearchProblem——每个都有官方 autograder。建议路径：

```bash
git clone --depth 1 -b v2.1.0 https://github.com/edulinq/pacai.git
pip install -r requirements.txt   # Pillow + edq-utils
# 实现 pacai/student/singlesearch.py 后：
python3 -m pacai.bin.pacman --solver bfs ...
```

把 8 个函数逐个做掉，等于把 CS188 的 Q1–Q4 全部吃透 / completing all eight is eating CS188 Q1–Q4 whole.
