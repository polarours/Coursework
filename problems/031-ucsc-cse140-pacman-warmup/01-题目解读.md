## 需求概述 / Requirements

UCSC CSE140 的 p0：Berkeley CS188 经典搜索项目的热身关。两个小题，Python：

UCSC CSE140's p0: the warm-up stage of Berkeley CS188's classic search project. Two small tasks in Python:

1. **buyLotsOfFruit(orderList)**：按 `FRUIT_PRICES` 价目表算一单水果总价；订单里出现店里没有的水果时返回 `None`。
   *Sum an order against a price table; unknown items yield None.*
2. **shopSmart(orderList, fruitShops)**：给定若干商店（各有自己的价格表），返回**总价最低**且能完整供货的商店对象。
   *Pick the cheapest shop that can actually fill the order.*

期望输出直接写在 starter 的 docstring 里（`Cost of [...] is 12.25`、`best shop is shop1`），天然可机器验证。

> **English:** p0 is deliberately tiny — a price lookup and an argmin — but it bootstraps the Pacman project's conventions: docstring-verified output, None for invalid orders, and object-level comparisons between shops.

## 边界条件 / Edge cases

- 订单含店里没有的水果 → `buyLotsOfFruit` 返回 None / unknown fruit → None
- `shopSmart` 遇到无法完整供货的商店应跳过（`getPriceOfOrder` 返回 None）/ skip shops that can't fill the order
- 空订单 → 总价 0.0 / empty order costs 0.0
- 浮点比较用容差（0.01）而非 `==` / compare floats with tolerance

## 明确不做 / Non-goals

- 不实现 p1 的搜索算法（DFS/BFS/UCS/A*，见 07 延伸练习与 README 的 p1 说明）/ p1 search algorithms are out of scope here.
