# 06 · 踩坑清单 / Pitfalls

## 1. docstring 与 main 输出不一致 / Docstring drift

- 症状 / Symptom：按 `shopSmart.py` docstring 期望断言 `best shop is shop1.`，测试失败。
- 实况 / Reality：`shop.py` 的 main 实际打印 `the best shop is shop1.`——**多了个 "the"**。
- 处理 / Resolution：断言以实际代码为准（`the best shop`），并在测试注释里说明出处。upstream 的注释性期望与可执行输出有细微出入——这类 drift 在真实课程仓库里并不少见，验证时要信**跑出来的**。
  *Trust what runs, not what the comment promises; upstream docstrings can drift from their own mains.*

## 2. `if price` 吞掉 0.0 单 / truthiness swallows a zero order

- 见 02 章：None 检查必须 `is not None`。

## 3. 浮点容差 / Float tolerance

- 直接 `== 12.25` 在累加路径上迟早翻车，用 `abs(x - 12.25) < 1e-9`（函数级）/子串匹配（输出级）。

## 4. 从解包克隆代码的验证边界 / Verification limits

- 031 的 upstream 是官方**作业下发仓库**，不含官方测试文件（评分在 pacai autograder）——所以自写测试的期望值必须全部锚定在 docstring 或算出的数值上，这正是 05 章"期望值来源"的纪律。
