# 04 · 正确性与复杂度 / Correctness & complexity

## 复杂度 / Complexity

| 函数 | 复杂度 | 说明 |
|---|---|---|
| buyLotsOfFruit | O(n) | n = 订单项数；dict 查价 O(1) |
| shopSmart | O(s × n) | s 个商店 × 每店一单 |

p0 规模下无优化可言；**真正要紧的是浮点**：价格相加在二进制浮点下有舍入（如 0.1+0.2），CS188 原版测试用 `abs(a-b) < 0.01` 容差——我们沿用，并对"总价恰好 0.0"用 `== 0.0`（此处无累加误差）。

> **English:** Float sums wobble in binary; the original CS188 tests use a 0.01 tolerance and so do we — but an empty order sums nothing, so exact zero is safe there.

## 正确性验证 / Verification

- 函数级断言 + main 输出逐字对照双保险 / function-level asserts plus literal stdout comparison.
- `shopSmart` 的对象同一性用 `is` 断言（不是值相等）/ identity assertions with `is`.
