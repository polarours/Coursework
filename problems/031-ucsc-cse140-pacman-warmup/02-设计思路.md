# 02 · 设计思路 / Design

## buyLotsOfFruit：查表归约 / A table-fold

一行核心：`sum(prices[f] * p for f, p in order)`——但要先处理缺货。**为什么先查再算 / Why check first**：Python 的 dict 索引对未知键抛 `KeyError`，题目约定的失败语义是返回 None（让调用方能区分"算不出"与"价格为 0"）。

> **English:** The failure mode is part of the API: returning None lets callers distinguish "unknown item" from a genuine zero.

## shopSmart：对象间的 argmin / An argmin over objects

商店是**对象**不是字典：`FruitShop.getPriceOfOrder(orderList)` 自己处理缺货（返回 None）。所以 shopSmart 的循环体只需三件事：

```python
price = fruitShop.getPriceOfOrder(orderList)   # None = 供不了这单
if price is not None and (bestPrice is None or price < bestPrice):
    bestShop, bestPrice = fruitShop, price
```

**为什么判 `is not None` 而不是 `if price`**：总价恰为 0.0 的合法订单会被 `if price` 误杀——None 检查必须用身份比较。

> **English:** `if price` would drop a legitimate 0.0 order; None checks must use identity, not truthiness.

## 返回对象本身 / Return the shop, not its name

题目要求返回 `FruitShop` 对象——测试用 `is`（同一性）断言。这为 p1 埋下伏笔：CS188 后续都在"返回对象/结构"而非"打印字符串"的层次上工作。
