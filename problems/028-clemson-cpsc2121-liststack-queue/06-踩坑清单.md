# 06 · 踩坑清单 / Pitfalls

## 1. 缺 return 的 UB 是最阴的 bug / Missing return, silent UB

- `size(){ stack.size(); }` 编译只给警告（部分编译器甚至不吭声），返回值是**栈上的垃圾**——偶尔"看起来对"，压测才翻车。审代码要拿"非 void 函数必有 return"当硬规则扫。

## 2. 官方样例≠官方测试 / Sample tests ≠ full tests

- 13 个样例全过不代表正确：五处缺陷**全部**在样例覆盖之外。真实课程的评分用例永远比公开样例多——边界测试必须自己补。

## 3. 接口注释是合同 / Interface comments are contracts

- "If no first node, return the default constructed value: T()" 写在头文件里，但 upstream 实现者没照做。**读题先读注释**，每个约定都值一条测试。

## 4. 空容器 remove 的两种死法 / Two ways empty-remove dies

- 解引用 nullptr 崩溃（本题）；或 `mySize--` 变成 -1 污染后续 size——修复版 no-op 返回，计数才始终 ≥ 0。

## 5. 大小写模板参数 / Template parameter casing（同 024）

- 学生仓库里 `AList<itemType>` 式笔误在编译期暴露——好修；真正的教训是**提交前先全量编译所有样例**，本题 13 个用例就是现成的回归套件。
