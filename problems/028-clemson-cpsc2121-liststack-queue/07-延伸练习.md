# 07 · 延伸练习 / Extensions

## 1. 给 upstream 版写"失败测试集" / A failing test set for the original

## 2. 尾指针升级 / Adding a tail pointer

`insertEnd` O(n) → O(1)：加 `_tail` 与反向链（双向表），重跑 13 样例。与 025 的头尾双指针、029 的环形哨兵三方对照——同一个优化在三个作业里的形态。

## 3. std::optional 重构 / Refactor to optional

把"空表返回 T()"升级为 `std::optional<T>`（025 的语义）：哪些调用点要改？官方样例还能原样过吗？——一次跨越 20 年的 C++ 接口演进实验。

## 4. 提交服务器化 / SubmitServer crossover

把 List 接进 030（UMD）的 SubmitServer 数据层：学生成绩存 List、按名查询——两个真实作业拼成一个迷你教务系统，练习"库的组合"。
