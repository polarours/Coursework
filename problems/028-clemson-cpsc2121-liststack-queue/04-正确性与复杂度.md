# 04 · 正确性与复杂度 / Correctness & complexity

| 操作 | 复杂度 | 说明 |
|---|---|---|
| insertStart / removeStart | O(1) | 头指针直动 |
| insertEnd | O(n) | 单向表走到尾（无尾指针） |
| removeEnd | O(n) | 走到倒数第二格 |
| find / getAt | O(n) | 线性 |
| push/pop/enqueue/dequeue | O(1)* | 转发到 List 的对应端（*dequeue 走头是 O(1)；enqueue 若实现为 insertEnd 则 O(n)——见下） |

**修复不改变复杂度**：五处全是边界行为修复；正常路径一行动都没动，官方 13 样例在两个版本上都过——缺陷全部藏在**官方用例没覆盖的空容器分支**。

> **English:** All five fixes live in branches the official tests never enter — that's exactly why "13/13 pass" was never proof of correctness.

## 正确性验证 / Verification

- 官方 13 样例（upstream 学生版 + 修复版都过 → 修复无回归）
- 边界 5 测试：空表四读、空栈 size/pop、空队列 dequeue、LIFO/FIFO 语义、insertAt/find/removeAt 组合——**只可能由修复版通过**
