# 05 · 调试与测试 / Debugging & testing

## 测试基建 / Harness

官方样例是**main 式断言文件**（T1–T22.cpp，各自带 main，跑通即过）。run.sh 循环编译运行 13 个用例，再补 `tests/edge.cpp`。头文件在 upstream 的 Lab 目录，`-I` 要带上（Node.h 不在样例目录）。

## 实测记录 / Verified runs

```
官方样例: 13 passed, 0 failed
== 边界测试（官方用例未覆盖的空表/空栈语义）==
Passed empty-list edges      （getFirst/getLast/getAt 返回 T()，remove 不崩）
Passed empty-stack edges      （size()==0、pop() 返回 T()）
Passed empty-queue edges      （dequeue() 返回 T()）
Passed LIFO/FIFO semantics
Passed List operations        （insertAt/getAt/find/removeAt）
ALL EDGE TESTS PASSED
```

## 审阅方法 / How the review was done

1. 先读接口注释圈出"合同语句"（返回值约定）
2. 再读实现找"没实现合同的路径"——空表/越界就是天然的未覆盖分支
3. 每处缺陷写一个能区分两版本的测试（upstream 崩溃、修复版通过）
   *Every defect gets a test that fails on the original and passes on the fix.*
