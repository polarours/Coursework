## 失败案例与排查 / Failures and debugging

| 症状 / Symptom | 原因 / Cause | 修复 / Fix |
|---|---|---|
| 测试超时 180s（RSA 生成卡死）| gen_prime 用固定种子 Random(2024)，每次返回同一素数，p==q 时 while 循环无限重试 | gen_prime 加 seed 参数，p/q 用不同种子 / different seeds |

> **English:** A fixed random seed is great for reproducibility but disastrous when the same generator is called twice expecting different values. This real deadlock is a classic trap.
