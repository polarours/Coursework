# 07 · 延伸练习 / Follow-up exercises

## 练习 1 — Diffie-Hellman（中等）
实现 DH 密钥交换，演示中间人攻击。 > **English:** Implement DH key exchange and a MITM demo.

## 练习 2 — Merkle 证明（困难）
实现成员证明与验证：给定叶子与索引，生成从叶子到根的路径哈希。 > **English:** Implement Merkle inclusion proofs.

## 练习 3 — RSA 正确性攻击（综合）
演示小 e 广播攻击或共模攻击，用真实数字说明为什么不能直接加密长消息。 > **English:** Demonstrate a low-exponent broadcast attack.
