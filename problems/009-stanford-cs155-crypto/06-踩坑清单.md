# 06 · 踩坑清单 / Pitfalls

## 1. 固定种子导致重复素数 / Fixed seed yields identical primes

RSA 需要两个不同素数；固定种子让两次 gen_prime 返回同一个，while p==q 死循环。修复：seed 参数区分。

## 2. 朴素模幂溢出/超时 / Naive modular exponentiation

必须用平方-乘快速幂；朴素循环在真实 RSA 的指数下不可用。

## 3. 素性测试的小数边界 / Small-number edge cases

Miller-Rabin 前先试除小素数，并单独处理 n<2 与 n 等于小素数的情况。

> **English:** The central pitfall was a genuine deadlock: a fixed random seed made two gen_prime calls return the same prime, so RSA's `while p == q` loop never terminated (the test timed out at 180s). The fix gives each prime a distinct seed. Two further notes: modular exponentiation must use square-and-multiply, and Miller-Rabin needs explicit small-number handling.
