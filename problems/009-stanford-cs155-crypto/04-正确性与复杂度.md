# 04 · 正确性与复杂度 / Correctness and complexity

## 不变量 / Invariants

1. RSA：decrypt(encrypt(m)) = m（当 m<n）。
2. 签名：verify(m, sign(m)) = True；篡改则 False。
3. Merkle：任一叶子变化 → 根变化（抗碰撞假设下）。

> **English:** Invariant 1 follows from Euler's theorem: (m^e)^d ≡ m^(ed) ≡ m (mod n) when ed ≡ 1 (mod φ(n)).

## 复杂度 / Complexity

| 操作 / Operation | 时间 / Time |
|---|---|
| 模幂 / mod_pow | O(log d) |
| Miller-Rabin（8 轮）| O(8 log n) |
| 密钥生成 | O(素数搜索次数 × log n) |
| Merkle 树 | O(n) 叶子哈希 |
