# 02 · 设计思路 / Design rationale

## 关键决策 / Key decisions

| 决策 / Decision | 选择 / Choice | 理由 / Why |
|---|---|---|
| 素性测试 | Miller-Rabin，8 轮 | 概率足够低且实现简单 / low error, simple |
| 模幂 | 快速幂（平方-乘）| O(log d)，避免朴素 O(d) / O(log d) |
| 随机数 | 固定种子 | 结果可复现（实测纪律要求）/ reproducible per evidence discipline |
| Merkle 树 | 两两配对哈希，奇数时复制 | 标准二叉树构造 / standard construction |

> **English:** mod_pow (fast exponentiation) is the engine: RSA with 16-bit primes would be fine naively, but real RSA uses 2048-bit exponents where O(log d) is essential.
