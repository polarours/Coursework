# 01 · 题目解读 / Understanding the problem

## 需求概述 / Requirements

Stanford CS155 的网络与系统安全课程包含密码学实践。本项目实现三个核心构件：
Stanford CS155's security course includes cryptography labs. We implement three core building blocks:

1. **Miller-Rabin 素性测试**：概率性判断大数是否为素数。
2. **RSA**：密钥生成、加解密、数字签名。
3. **Merkle 树**：把一组数据汇总成一个哈希根，用于完整性验证。

> **English:** These are the primitives behind HTTPS, software signing, and blockchains. Implementing them by hand demystifies the math.
