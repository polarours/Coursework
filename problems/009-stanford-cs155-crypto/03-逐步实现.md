# 03 · 逐步实现 / Step-by-step implementation

## 阶段 1 — Miller-Rabin

分解为 n-1 = d·2^r；对若干随机底数检查 a^d ≡ 1 或中途出现 n-1。

## 阶段 2 — 快速模幂

```python
while d:
    if d & 1: res = res * a % n
    a = a * a % n
    d >>= 1
```

验证 / Verify: mod_pow(2,10,1000)=24。

## 阶段 3 — RSA

p,q 互异素数 → n=pq, φ=(p-1)(q-1) → e 与 φ 互质 → d=e⁻¹ mod φ。

验证 / Verify: encrypt/decrypt 往返成功；签名验证正确。

## 阶段 4 — Merkle 树

叶子 SHA-256，两两配对哈希至根。

验证 / Verify: 篡改任一叶子，根改变。

> **English:** The e=65537 choice follows real-world RSA practice (Fermat prime with few 1-bits, faster encryption).
