# 02 · 设计思路 / Design rationale

## 关键决策 / Key decisions

| 决策 / Decision | 选择 / Choice | 理由 / Why |
|---|---|---|
| 组相联 LRU | OrderedDict，move_to_end | O(1) 实现 / O(1) |
| 写策略 | 写回 + 脏位 | 减少内存写 / fewer writes |
| 地址划分 | offset=addr%bs, set=(addr/bs)%sets, tag=(addr/bs)/sets | 标准公式 / standard |

> **English:** The address decomposition is the key mental model: block offset picks a byte within a line, set index picks a cache set, tag identifies which block is resident.
