## 输出解读 / Reading the output

- 直接映射中地址 0 和 8 的块地址分别为 0 和 2，都映射到 set 0（2 个组），tag 不同 → 反复冲突。
- 2 路组相联让 0 和 8 共存于 set 0 的两路 → 后两次访问命中。

> **English:** All tests passed. Sequential access reached a 0.5 hit rate versus 0.0 for stride-64, a direct demonstration of spatial locality. A dirty line eviction produced exactly one writeback. The direct-mapped vs 2-way comparison (0 hits vs 2 hits) shows how associativity reduces conflict misses.

## 失败案例与排查 / Failures and debugging

本实现测试一次通过，未遇到真实失败；下表为根据机制推导的**预防性**易错点（非实测 bug）。
The implementation passed on the first run; no real failure occurred. The table lists **preventive** pitfalls derived from the mechanism, not observed bugs.

| 症状 / Symptom | 原因 / Cause | 预防 / Prevention |
|---|---|---|
| 命中率异常低 / Abnormally low hit rate | 命中时未更新 LRU / LRU not updated on hit | move_to_end on every hit |
| 地址划分错乱 / Wrong address split | 组数或块大小非 2 的幂 / non-power-of-two sizes | assert powers of two at init |
| writeback 计数为 0 / Missing writebacks | 淘汰脏行时未计数 / dirty eviction not counted | check dirty bit before eviction |
