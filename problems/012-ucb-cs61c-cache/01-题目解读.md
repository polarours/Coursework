# 01 · 题目解读 / Understanding the problem

## 需求概述 / Requirements

CS61C 的 cache 实验让学生理解存储器层次。本项目实现一个可配置的 cache 模拟器：

1. **地址划分 / Address split**：tag | set index | block offset。
2. **直接映射与 N 路组相联**。
3. **统计 / Stats**：hit、miss、eviction、writeback。

> **English:** A cache simulator makes the memory hierarchy concrete: you can see exactly which accesses hit and why conflicts happen.

## 验收 / Acceptance

- [x] 直接映射冲突序列全 miss；2 路组相联命中 2 次
- [x] 顺序访问命中率 0.5 > 跨步访问 0.0
- [x] 脏行淘汰触发 1 次 writeback
