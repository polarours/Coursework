# 03 · 逐步实现 / Step-by-step implementation

## 阶段 1 — 地址划分

```python
offset = addr % block_size
block_addr = addr // block_size
set_idx = block_addr % num_sets
tag = block_addr // num_sets
```

## 阶段 2 — 访问与替换

命中：move_to_end，写则标脏。未命中：满则淘汰 LRU（脏则 writeback），装入新行。

验证 / Verify: 直接映射 0/8 冲突全 miss；2 路组相联命中 2 次。

## 阶段 3 — 统计

验证 / Verify: 顺序 hit_rate 0.5 > 跨步 0.0；写回 1 次。

> **English:** Three stages: address decomposition (offset, set index, tag), access with LRU replacement and dirty-bit updates, and statistics collection. The direct-mapped sequence [0,4,8,0,8] misses every time because addresses 0 and 8 map to the same set with different tags; 2-way associativity lets them coexist and produces two hits.
