# 07 · 延伸练习 / Follow-up exercises

## 练习 1 — 全相联（中等）
实现 fully associative cache，对比冲突缺失。 > **English:** Implement a fully associative cache.

## 练习 2 — 写分配策略（困难）
实现 write-through 与 write-allocate 两种策略，对比写流量。 > **English:** Compare write-through vs write-back traffic.

## 练习 3 — 真实程序 trace（综合）
用 valgrind 或插桩生成真实访存 trace 喂给模拟器。 > **English:** Feed a real memory trace from a program into your simulator.
