# 06 · 踩坑清单 / Pitfalls

## 1. 两处序列化不一致 / Inconsistent serialization

- 症状 / Symptom：commit 时 `FileNotFoundError`，uid 对应的对象文件不存在。
- 原因 / Cause：`__post_init__` 与 `_save_commit` 各自 pickle 了不同的数据结构。
- 修复 / Fix：统一 `Commit._serialize()`，并加 `assert uid == c.uid`。
- 实测 / Evidence：这是开发中真实遇到的错误，已记录在 05。

> **English:** Hash-based storage demands one canonical byte representation. Any second serialization path is a latent bug.

## 2. 忘记去 blob 前缀 / Forgetting to strip the blob prefix

- 症状 / Symptom：checkout 后文件内容多出 `blob:` 字样。
- 修复 / Fix：读取时用 `data.replace(b"blob:", b"", 1)` 去掉前缀。

## 3. 空暂存区也能提交 / Empty staging commit

- 症状 / Symptom：产生内容完全相同的重复提交。
- 修复 / Fix：`commit` 开头检查 `if not stage: return "No changes added..."`。

## 4. 分支与 HEAD 脱节 / Branch and HEAD out of sync

- 症状 / Symptom：commit 后 log 仍显示旧内容。
- 修复 / Fix：commit 时同时 `_set_head` 与 `_set_branch`。

## 5. 时间戳用真实时间导致 uid 不稳定 / Real timestamps make uids unstable

- 症状 / Symptom：同样的提交每次 uid 不同，不便测试。
- 修复 / Fix：教学版用递增整数当时间戳（`float(len(_log_uids()))`），输出中可见 Date: 0.0/1.0/2.0。
