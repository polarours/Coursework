# 07 · 延伸练习 / Follow-up exercises

## 练习 1 / Exercise 1 — 真实 diff（中等）

当前提交存整棵树快照。请实现 `gitlet diff`：对比工作区与 HEAD 的树，输出哪些文件被修改、新增、删除；用真实文件操作验证。

提示 / Hint：遍历两棵树的键集合，比较 blob hash；对修改的文件可输出简化的一行摘要。

> **English:** Implement `diff` by comparing the working directory with HEAD's tree. This teaches that diffs are derived from snapshots, not stored separately.

## 练习 2 / Exercise 2 — 分支与合并（困难）

实现多分支：`branch <name>`、`checkout <branch>`，以及两分支的 `merge`。无冲突时快进或三方合并；有冲突时输出冲突文件。

提示 / Hint：三方合并需要找到公共祖先（LCA），对三个版本逐文件比较；相同修改自动合并，不同修改标记冲突。

> **English:** Add branches and a three-way merge with conflict detection. Find the lowest common ancestor of the two branch heads and merge file-by-file.

## 练习 3 / Exercise 3 — 对象压缩与打包（综合）

用 `zlib` 压缩对象；实现 `gc` 命令回收不可达对象；设计 packfile 把多个对象打成一个文件并建立索引。

提示 / Hint：从 HEAD 出发遍历 parent 链与树，标记可达对象；删除未标记的。

> **English:** Compress objects with zlib, implement `gc` by marking objects reachable from HEAD, and design a simple packfile format with an index.
