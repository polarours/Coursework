# 03 · 逐步实现 / Step-by-step implementation

## 阶段 1 / Stage 1 — init

创建 `.gitlet/objects` 与 `.gitlet/refs/heads`，写入 initial commit（空树、无父提交）。

Create the object store and refs; write an initial commit with an empty tree and no parent.

```python
c = Commit("initial commit", 0.0, None, {})
self._save_commit(c)
self._set_branch("master", c.uid)
self._set_head(c.uid)
```

验证 / Verify: `.gitlet/objects` 目录存在。

## 阶段 2 / Stage 2 — 内容寻址存储

```python
def _write_object(self, data: bytes) -> str:
    uid = hashlib.sha1(data).hexdigest()
    ...
```

验证 / Verify: `add("hello.txt")` 返回空串（成功），暂存区记录文件名 → blob hash。

## 阶段 3 / Stage 3 — commit

从暂存区取文件，合并到父提交的树，创建新提交并推进 HEAD。

Merge staged files into the parent's tree, create a new commit, and move HEAD.

```python
tree = dict(parent.tree)
tree.update(stage)
c = Commit(message, float(len(self._log_uids())), parent.uid, tree)
```

验证 / Verify: 两次 commit 的 uid 分别为 `cfae5a4`、`828f05d`（真实输出）。

## 阶段 4 / Stage 4 — log / status

沿 parent 链回溯打印历史；status 显示当前分支、head、暂存区。

Walk the parent chain for log; show branch, head, and staging area for status.

验证 / Verify: log 显示 3 个提交，newest 在前；status 显示 `Head: 828f05d`。

## 阶段 5 / Stage 5 — checkout

从 HEAD 提交的树中取文件的 blob，写回工作区。

Read the file's blob from HEAD's tree and write it back to the working directory.

```python
blob = c.tree[filename]
data = self._read_object(blob)
(root / filename).write_bytes(data.replace(b"blob:", b"", 1))
```

验证 / Verify: 文件被改坏后 checkout，恢复为 `hello gitlet\n`。

> **English:** The blob is stored with a `blob:` prefix to distinguish it from commit objects. checkout strips that prefix — a small detail that matters when both object types share one directory.
