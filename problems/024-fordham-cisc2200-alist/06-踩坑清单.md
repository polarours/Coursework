# 06 · 踩坑清单 / Pitfalls

## 1. `resize(count * RFACTOR)` 的隐性缩容 / Shrinking by accident

- 症状：满表后再插入，容量计算反而变小 → 越界写
- 原因：参数用 `count`（当前元素数）而非 `maxCnt`（当前容量）
- 修复：扩容一律 `maxCnt * RFACTOR`

## 2. 浅拷贝 double free / Shallow-copy double free

- 症状：两对象析构时同一指针删两次
- 修复：拷贝构造/赋值必须三步走（抄形状 → 开新内存 → 搬内容）

## 3. 后移方向反了 / Shifting the wrong way

- `items[i] = items[i+1]`（前移写法误用于插入）会把头部覆盖——addFirst 必须从尾往头搬

## 4. 模板大小写 / Template case sensitivity

- `itemType` vs `ItemType`：模板参数名不一致是**编译错误**不是警告，这类 starter 笔误在真实课程仓库里并不少见

## 5. doctest 的普通断言 / Plain asserts

- doctest 的 `CHECK` 失败不终止，`REQUIRE` 终止——选错会掩盖后续用例的连锁失败
