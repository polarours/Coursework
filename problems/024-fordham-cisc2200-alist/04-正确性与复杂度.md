# 04 · 正确性与复杂度 / Correctness & complexity

| 操作 | 复杂度 | 说明 |
|---|---|---|
| addLast | 均摊 O(1) | 偶发 resize O(n) |
| addFirst | O(n) | 整体后移 |
| get / getFirst / getLast | O(1) | 直索引 |
| removeFirst | O(n) | 整体前移 |
| 拷贝构造 | O(n) | 逐元素 |

**均摊的来源**：RFACTOR 倍增（2x）意味着 n 次插入的总搬运 ≤ 2n；若按 +1 增长则退化为 O(n²)。

> **English:** Geometric growth makes n pushes cost O(n) total; +1 growth makes the same O(n²). The one-character difference between `maxCnt * RFACTOR` and `count + 1` is the whole amortization story.
