# 03 · 逐步实现 / Step-by-step implementation

## 1. resize：搬运工 / The workhorse

```cpp
void resize(int capacity) {
    maxCnt = capacity;
    ItemType *a = new ItemType[maxCnt];
    for (int i = 0; i < count; i++) a[i] = items[i];   // 只搬有效区
    delete[] items;
    items = a;
}
```

**为什么先开后删** / *Why allocate before deleting*: 若 new 抛异常，旧数组仍在——异常安全的基本操作顺序。

## 2. addFirst：先扩容、再后移、后落位

```cpp
void addFirst(ItemType x) {
    if (count == maxCnt) resize(maxCnt * RFACTOR);   // 用 maxCnt 不是 count
    for (int i = count; i > 0; --i) items[i] = items[i-1];
    items[0] = x;
    count += 1;
}
```

## 3. 拷贝构造 / copy constructor

```cpp
AList(const AList<ItemType> &other) {
    maxCnt = other.maxCnt;  count = other.count;
    items = new ItemType[maxCnt];
    for (int i = 0; i < count; i++) items[i] = other.items[i];
}
```
